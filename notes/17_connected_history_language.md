# 17 —— 空三行棋盘全部连通后继的唯一语言与精确计数

日期：2026-10-14。状态：`[推导]`，宽 1/2 的有限基例另作穷尽核验。
未核查首创性。本节对象是**空 `3×n` 的全部合法历史、全部连通分量**，
不要求外行覆盖、固定核心、周期词或有限个缺陷。

主要结论是一个几何分类，不是空盘 SG 周期定理：内部历史形成五状态自动机；
端点的少量歧义可以规范化，得到每个连通分量的唯一编码、精确计数和无哈希的
完整 SG 求值表。指数仍在，但底数和它的来源现在有任意宽度的证明。

## 1. 保持连通且横跨全部列的后继，恰好是一个正则语言

行位 `1,2,4` 分别表示上、中、下行。合法落子历史等价于原棋盘中的一个独立集
S；落子顺序不影响剩余集合 `F_n \ N[S]`。外行词 `H∈{0,1,4}^n` 在非零列
落相应外行子。称 H 正则，当连续两个非零字母的列距满足：

- 同行至少 2；
- 异行至少 3。

**全跨连通定理。** `F_n \ N[S]` 非空、连通且列跨度仍为 `1..n`，当且仅当
S 恰为一个正则外行词。不同正则词产生不同剩余掩码。

必要性：中行落子删空所在列，连通分量不能跨过它。两外行同列或相邻列
落子删空阻断列；异行相距 2 时，中间列只剩孤立中格，左右各在两侧落子列
止步（notes/12 的 O 分类）。任何进一步删除也不能重新连接这些片。
因此全跨分量排除了所有这类落子。同一外行相邻落子本来就不合法。

充分性可直接按列证明，而不诉诸枚举。正则词每列都非空，且列内连通：
落子列仅剩另一外格；未落子列的中格幸存。两个相邻未落子列由中行边相接。
落子列的剩余外格也在相邻列幸存，否则必须有另一外行落子在距它不超过 2
的位置，与正则条件矛盾。因此每对相邻列都有连接边，整个图连通且全跨。
同一论证说明限制到任意连续列段时，列内连通和相邻连接仍成立。

一一对应性：哪列缺中格，哪列就是落子列；该列仅剩外格 b 时，原落子方向
恰为 `5 xor b`。所以历史可从剩余掩码恢复。

设正则词数为 `a_n`。末两列记忆只有五种状态 `00,01,10,04,40`。
把它们按上下对称聚合为：

```
u = 最近两列都未落子；v = 最近一列落子；w = 倒数第二列落子。
(u,v,w) → (u+w, 2u+w, v).
```

这个三阶矩阵的特征多项式是 `x³−x²−x−1`，故

\[
a_0=1,\quad a_1=3,\quad a_2=5,\qquad
\boxed{a_n=a_{n-1}+a_{n-2}+a_{n-3}\quad(n\ge3).}
\]

生成函数 `(1+z)²/(1−z−z²−z³)`。因此全跨连通后继的数量恰为
`Θ(ρ^n)`，其中 `ρ=1.839286755214…` 是上述多项式的唯一正根。
这是**不同几何局面的数量**，不只是历史数上界。

## 2. 任意连通分量只有有限的边界例外

现在 C 是任意宽空盘任意合法历史后的非空连通分量；平移其列跨度为 `1..n`。
先保留原历史中这 n 列内的落子，得到 H。

中行子不可能在其跨度内；两外行近距离的分割也不可能被一个连通 C 跨越，
所以 H 正则。跨度外的落子只可能进一步删除第一列或最后一列，其删除掩码
属于 `D={0,1,2,4,5}`：邻列独立集只能为空、单点或两外点。

若 `n≥3`，第一节说明正则词剩余图的内部列 `2..n−1` 全部连成一片。
C 跨越它们，故这些列的所有剩余格都必须在 C 中。与 C 不同的格只能在两端。
于是内部词完全可恢复：

```
2≤i≤n−1：第 i 列有中格 ⇒ H_i=0；
          第 i 列只剩外格 b ⇒ H_i=5 xor b。
```

两端有一个真正的歧义：外面的中行子可删掉端点中格，端点一个外格又可能
成为另一个孤立分量。若第一列只剩外格 b、第二列有中格，规范地置
`H_1=5 xor b`；否则置 `H_1=0`。右端同理。

为什么这种重编码不改变内部？若原历史没有第一列子，而上述规则加入了
方向 x，那么原端点删除只能是外部中行子。被 C 排除的第一列 x 格必须孤立，
因此第二列 x 格已被第三列 x 子删除。新加入的第一列 x 子仅重删第二列已缺
的格，且与第三列子同行相距 2，仍正则。原本已有第一列子则本规则直接恢复。
没有第二列中格时，第二列已有子，第一列不可能再有子。

这给出唯一的**规范词** H。端点剩余列随最近落子距离 d 有如下唯一删除项：

| 端点向内最近落子距离 d | 允许的规范端点删除 | 数量 |
|---|---|---:|
| 0 | `0` | 1 |
| 1 | `0,2` | 2 |
| 2 | `0,1,4,5` | 4 |
| ≥3，或没有落子 | `0,1,2,4,5` | 5 |

逐行理由：d=0 的端点只剩一格，必须保留；d=1 时端点落子侧外格已缺，
删中格可保留与内部连接的另一外格，删另一外格则只留一个孤立中格。
d=2 时删中格正是刚才的孤立角格歧义，规范化后已有端点子，故从该行移除
删除项 2；其他四项都连接内部。d≥3 时第二列完整，五项都连接内部。
右端完全相同；两个端点分别接入共同内部，选择可独立组合。

因此，对 `n≥3`，唯一编码是：

\[
\boxed{(H,L,R),\quad H\text{ 正则},\quad
L\in D_{d_L(H)},\ R\in D_{d_R(H)}.}
\]

它精确保留全部格子，**不是用 SG 值或接口 SG 表替换几何**，因而不触犯
notes/13 的接口反例。一般三行诱导图不一定属于此语言：例如四列直线外行
路径不可这样恢复，任意缺损输入不能直接交给本节的专用编码器。

## 3. 反方向：每个编码都真实可达，且只须加四列

对任一上述规范编码，在词 H 两侧按需各加两列。先执行 H。
非零左端删除 L 按下列独立集阻断外部；列 0 紧挨原第一列：

```
L=2：在 (中,0) 落子；
L=5：在 (上,0),(下,0) 落子；
L=1：在 (上,0),(下,−1) 落子；
L=4：在 (下,0),(上,−1) 落子。
```

右端镜像构造。表中允许 d 保证这些子与内部 H 合法；外部子所在列被删空，
或两异行相邻子共同删空边界列，所以阻断外部连接。对内部只留下指定端点
删除。上节已保证剩余内部全跨连通，故它恰好是一个分量。

由此，规范编码的每个局面都能在宽度不超过 `n+4` 的空三行盘出现。
这不是包含一些不合法状态的宽松包络，而是**全部可达连通几何的精确分类**。

宽 1 只有 `1,2,3,4,6,7` 六个连通列。宽 2 的 28 个全跨连通诱导掩码中，
四个列词 `17,47,71,74` 不可达，剩余恰 24 个。不可达性：一列完整为 7、
邻列只剩单个外格。为保留完整列，跨度内不能有任何落子，否则会删去完整
列中或其横邻的格。外面的子只对单格列施加 D 中的一项删除，这五项均不能
将完整三格变成单个外格，矛盾。24 个正例由正则长度 2 词及 D 的两端删除
逐一给出，使用同一个至多四列的见证构造；实现保存这个有限字典。

## 4. 全部连通几何的精确计数

令 `c_n` 为允许任意原棋盘宽度、所有历史后，列跨度恰为 n 的不同连通掩码数，
只做列平移，尚未除上下/左右反射。定义

```
f(H) = H 的前三列首个非零字母距左端为 d<3 时取 2^d；否则取 5。
```

唯一编码定理立即给出

\[
c_n=\sum_{H\in\mathcal L_n} f(H)f(H^{rev})\quad(n\ge3).
\tag{1}
\]

**精确计数定理。**

\[
c_1=6,\ c_2=24,\ c_3=51,\ c_4=89,\ c_5=163,\ c_6=301;
\qquad
\boxed{c_n=c_{n-1}+c_{n-2}+c_{n-3}\quad(n\ge7).}
\]

证明不是拟合数字。长度达到 3 后，每个词的左权重 f 已冻结。按该权重聚合
第一节的三个状态，仍按同一矩阵更新；长度 3 向量是 `(u,v,w)=(7,10,4)`。
右权重为“末列子取 1、倒数第二列子取 2、倒数第三列子取 4、更早取 5”，
所以对 `n≥4` 有 `c_n=5u_n+v_n+2w_n−w_(n−1)`。矩阵满足三阶特征方程，
从而这个输出从 n=7 起满足同一递推。它给出 c4..6，而 c3 直接加权得 51。

生成函数为

\[
\sum_{n\ge1}c_nz^n=
\frac{6z+18z^2+21z^3+8z^4-z^5-2z^6}{1-z-z^2-z^3}.
\]

因此 `c_n=Θ(ρ^n)`；总跨度不超过 n 的状态数也为 `Θ(ρ^n)`。
`ρ²=3.382975767906…` 与旧 C 求解器实测每两列约 3.38 倍增长一致。
严谨含义是我们解释了**全可达几何族**的指数；旧求解器只访问其中一部分，
还除反射、跳过部分图，不能把它的条目数与 c_n 混为一谈。

## 5. 不保存掩码的完整 SG 表，直接适用于空盘

按正则词的字典序排列，再按左右端点删除序排列，即为无碰撞完美编号。
自动机保存前一子方向、距它的距离（截到 4）、前三列的左权重，后缀计数
可在 O(n) 个常数状态中预计算。逐列跳过较早分支的后缀数量，即在 O(n)
时间得到编号；反向解码用同一表。宽 1/2 直接索引有限字典。

任意编码的每手后继分量仍真实可达，所以都重新进入此编号系统。精确递推为

\[
g(M)=\operatorname{mex}\{\mathop{\mathrm{xor}}_{C\in\mathrm{comp}(M\setminus N[v])}
g(C):v\in M\}.
\]

着法严格减少格子数，故递推无环。以列跨度重新平移、编码，不再携带原棋盘
宽度、区间坐标或区间之外的历史。常数时间位集操作模型下，分量/编号 O(n)，
每状态 O(n) 手，得到 **O(n²ρ^n) 时间、O(ρ^n) 表条目**的完整空盘算法。
若位集不能装入机器字，还须计入相应字长成本；这不是多项式时间结论。

每个连通状态 SG≤顶点数≤3n。当前 C 版支持 `n≤42`，因此一个字节足够：
0 表示未算，g+1 表示已算。SG 表既无掩码键、也无哈希装载率空槽，严格容量为
`Σ_(k≤n)c_k` 字节（尚未扣反射重复）：

| 最大跨度 n | 全部连通状态表字节数 |
|---:|---:|
| 22 | 11,303,698 |
| 28 | 437,641,142 |
| 30 | 1,480,529,438 |
| 32 | 5,008,595,272 |
| 33 | 9,212,242,967 |
| 36 | 57,320,994,298 |

这把 `3×33` 的最坏表容量降到本机内存以内，但运行时间仍可能很长，本节没有
计算 `f(33)`。表在各宽度首次使用时按需分配；元数据、栈和分配器还有额外开销。
`STRIP3_LANGUAGE_BYTES` 明确控制字节预算，超额退出且不为未完成局面输出值。

本机同一优化等级、单线程 `strip 22` 的一次对比：旧 C 版 5.82 秒、
2,097,152 个 16 字节主表槽；新编号版 11.06 秒、11,303,698 个 SG 字节。
新版本按列计算编号，牺牲查询时间换内存；这次测量**没有提速结论**。
旧版另有宽键表，新版另有自动机元数据，所列数字比较 SG 主存储而非峰值 RSS。

代码与复现：

```bash
make build-strip3-language
make test-strip3-language
./src/cfast/strip3_language strip 22
python3 scripts/strip3_history_language.py --width 12 --solve --dense
# SG=5；SG 字节表总容量 25,486。
python3 scripts/strip3_history_language.py --width 33
# 只计算容量，不发起大搜索。
```

`scripts/strip3_history_language.py` 是可读的构造器、解码器、完美编号及求值器。
`src/cfast/strip3_language.c` 使用原 C 的位集几何和路径表，重写 SG 存储/查询；
保留路径/环、严格旋转和等分量抵消归约。它保留物理三行，仅做矩形反射：
随意挪动空行或转置嵌入可能离开可达语言，故不做这种几何规范化。

## 6. 独立核验和目前的数学边界

`tests/test_strip3_history_language.py` 以坐标集合独立实现所有合法历史、
闭邻域删除和连通性，不用构造器的位集删除或间距判定。已通过：

- `n≤9` 的全部 198,273 个合法历史，614,403 个实际连通分量；全跨连通后继
  数逐宽严格等于 a_n。全部历史含中行、同列两外行等分割情形。
- 宽 `≤12` 的全部 25,486 个编号无碰撞、可反向解码、有至多四列填充的合法
  历史见证；宽 `≤9` 的全部 62,000 手都重新进入语言。
- `3×5` 内全部 4,600 个列平移规范连通诱导子集，精确接受 333 个可达形状，
  拒绝 4,267 个不可达形状。正例与穷尽真实历史比较，而非只核验自行生成的词。
- 坐标子集 mex 独立核对 4,075 个组件值及 62,000 个实际选项；空盘到 12 一致。
- C 版各八种归约设置下的 7,516 个 SG 输入，8,116 项完美编号（含随机宽
  18/29/32/33/40/42），空盘到 22 一致；字节预算、非法输入和不可达图被拒绝。
- 宽至 80 的 600 个随机大编号/历史见证及 1,828 个随机实际组件核验。

审计数据为 `data/proofs/strip3_history_language_audit.json`。这些有限检查用于
交叉核验解码/实现；任意宽度的语言和计数由前文证明，而不是把测试当归纳。

第一节还给出一个结构事实：每个内部外行落子列只剩单个外格，任何连通分量
横跨该列时，该格是割点，两条水平连接边都是桥。因此所有环和真正厚的块
只会存在于相邻落子列之间的未落子段。空三行盘的困难已经被定位为**沿一条
链连接的厚块之间的博弈相互作用**；不能因存在割点就将两块 SG 直接 xor，
因为这两个部分共享可下的割点，notes/13 也禁止只靠 SG 摘要拼接。

本节覆盖了完整空盘及其全部后继，形状限制已经消失。但几何自动机是有限的，
并不等于 SG 或连接等价自动机有限；精确计数也不是“任何算法必须枚举这么多
状态”的复杂度下界。下一步有价值的问题是能否用包含共享割点全部选项的
接口代数处理厚块连接，或证明某些厚块有任意上下文替换规则。空盘长期零点、
SG 有界性及最终周期仍未证明。
