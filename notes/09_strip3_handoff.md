## 游戏、记法与当前可靠结果

局面用“仍可下的顶点”表示。落子于可下点 `v` 后，删除 `v` 及其在局面中的
上下左右邻点；无合法着法者负。对不相邻分量，SG 值异或；局面值是全部选项值
的 mex（最小未出现非负整数）。零值为 P-位置。

数学坐标：行 `r=1,2,3`（上、中、下），列 `c=1..n`。程序三行位编码：
`bit_index=3*(c-1)+(r-1)`，即列主序。Python 参考及旧配对工具用行主序，转换是
`row_major_index=(r-1)*n+c-1`，不能直接混用掩码。

记 `F_n` 为完整条带；`A_n` 为删除右端中格 `(2,n)` 的条带；`D_n` 为删除
两端中格 `(2,1),(2,n)` 的条带。相应 SG 为 `f(n),a(n),d(n)`。`n=0` 均为空图、
值 0；`D_1` 的两个缺口是同一格，只删一次。

已有证明（见 `notes/08_strip3_reductions.md`）：

| 原局面 | 中行第 i 列落子的合法范围 | 后继 SG |
|---|---|---|
| `F_n` | `1≤i≤n` | `a(i-1) xor a(n-i)` |
| `A_n` | `1≤i<n` | `a(i-1) xor d(n-i)` |
| `D_n` | `1<i<n` | `d(i-1) xor d(n-i)` |

此外：

- `d(t)=0, t≥1` 推出 `a(k+t+1)≠a(k)`，对所有 `k≥0` 成立。证明是找到
  `A_(k+t+1)` 的合法中行一手，使后继为 `A_k + D_t`，再用 mex 排除。
- `D_1` 是两个孤立点，`D_2` 是两个独立二点路径，故二者由异或抵消而值 0。
  长度差 2、3 的排除不依赖大规模计算。当前其他已算零尾巴长度为
  `6,10,16,24,28`，给出长度差 `7,11,17,25,29` 的全尺寸排除。
- 若 `a(p)=a(q)`，`3×(p+q+1)` 的中行第 `p+1` 列制胜。因此已知辅助值给出
  `3×32,34,38,40,42,48,52` 的明确制胜证书，未求这些整盘的精确 SG。
- `3×30,36` 的全部中行首着已逐着排除，证据在 `data/strip3_analysis.json` 的
  `middle_screens`。这不判定整盘胜负，仍需检查边行。
- 整盘精确调查到 `n=28`，零点恰为 `4,22,26`，新增 `f(28)=5`。
- `3×10` 没有中行胜着，但上/下边行第 4、7 列制胜，故 `b(10,4)=b(10,7)=0`。
  这是证明“中行条件不是完整 P 分类”的最小现有偶数例子。

## 待证的第一组引理：单个边行缺口的端口切割

以下定义和公式提供明确起点。交接时已对 `n≤14` 的 2457 个合法中行着法做过
掩码等式检查，未发现反例；**下一 agent 仍须写出任意 n 的证明并保存独立测试**。

定义缺口集合

```text
S(n,j) = {(1,j-1),(1,j),(1,j+1),(2,j)} 与棋盘的交集，1≤j≤n。
B_(n,j) = F_n 删除 S(n,j)                 （上边行第 j 列首着之后）
E_(n,j) = B_(n,j) 再删除 (2,1)            （左端中格缺口）
H_(n,j) = B_(n,j) 再删除 (2,1),(2,n)      （双端中格缺口）
```

分别记 SG 为 `b(n,j),e(n,j),h(n,j)`。重复删除同一格没有额外效果。`B` 的下边行
连续，因此各部分常常仍连通；切割公式按左右不相邻子图异或，即使子图内部
进一步分裂也成立。`E,H` 的定义是诱导局面，不要求它们一定由某个实际对局历史到达。

**L1：端口与缺口切割引理（优先证明）。** 在上述局面中下中行第 i 列，
合法性为 `B: i≠j`，`E: i≠1,j`，`H: i≠1,n,j`，并且 `1≤i≤n`。

| 原局面 | i 与 j 的关系 | 待证明的后继 SG |
|---|---|---|
| `B_(n,j)` | `i<j` | `a(i-1) xor e(n-i,j-i)` |
| `B_(n,j)` | `i>j` | `e(i-1,i-j) xor a(n-i)` |
| `E_(n,j)` | `i<j` | `d(i-1) xor e(n-i,j-i)` |
| `E_(n,j)` | `i>j` | `h(i-1,j) xor a(n-i)` |
| `H_(n,j)` | `i<j` | `d(i-1) xor h(n-i,j-i)` |
| `H_(n,j)` | `i>j` | `h(i-1,j) xor d(n-i)` |

证明时先证明左右**掩码/诱导图**的分解，再取 SG。`B` 在 `i>j` 的左段需左右
反射后认作 `E_(i-1,i-j)`；不要遗漏此索引变换。检查 `j=1,n`、`|i-j|=1`、
短段长度 1/2、重复端缺口等边界。这些公式只覆盖中行着法，不能单独取 mex
得到 `b,e,h`，因为边行着法同样合法。

同时证明 `b(n,j)=b(n,n+1-j)`、`h(n,j)=h(n,n+1-j)`。`E` 只有左端缺口，
一般不能直接声称 `e(n,j)=e(n,n+1-j)`；其反射是右端缺口版本。

**L2：新家族的零尾巴延伸引理（L1 之后）。** 若 `d(t)=0,t≥1`，令 `q=t+1`，
对 `n≥1,1≤j≤n` 尝试证明：

```text
e(n+q,j+q) != e(n,j)        左侧添加 q 列，中行 q 列切开
h(n+q,j+q) != h(n,j)        同样左侧添加
h(n+q,j)   != h(n,j)        右侧添加 q 列，中行 n+1 列切开
```

预期证明都是“一手到旧局面 + D_t，再用 mex”。另一个可用关系是：若 `a(t)=0,
t≥0`，则 `e(n+t+1,j)≠h(n,j)`；在较长 `E` 的中行第 `n+1` 列落子，留下
`H_(n,j)+A_t`。先验算合法性再推广，不要把不同家族的数值排除误写为图同构。

**L3：带端口拼接的等价/闭合性（探索目标，不能预设成立）。** 检查
`F,A,D,B,E,H` 加路径、环是否足以表示各家族的所有合法后继。边行再落子会产生
第二个缺口，通常应当需要新族。输出最小反例掩码、原局面参数、着法、剩余分量，
明确反例针对的是所声明的**几何模板表示**，不据此断言不存在 SG 或游戏等价。

若提出有限接口替换规则，必须说明接到哪种外部条带、保留哪些跨接口边，并证明
在这些拼接上下文里替换有效。相同 SG 值只保证不相邻和中可替换；沿边相接时
不能直接替换。三位列字母只有 8 种，也不证明接口游戏等价类有限。
