# 05 —— 开放问题、猜想与研究路线

状态截至当前数据作业。编号对应 `RESULTS.md` 中的相关条目。

## 文献中的开放问题

**O1. 混合奇偶性分类。** 在 `m` 偶 `n` 奇（或反之）的棋盘中，哪些是
P-位置？已知：`2 × 偶数`（P）、`4 × n` 对一切 n（P）、`3 × 4`，另有若干孤立
零点；`3 × 3, 5, 6, …` 为 N。Brown et al. 2020 明确把 `n × 3` 格盘与一般
情形列为开放。

**O2. 格盘上的复杂度。** 一般图上 Node Kayles 是 PSPACE-完全（Schaefer
1978）。在 `m × n` 格盘上（`m, n` 都是输入的一部分），胜负判定是否多项式
时间可解？连宽度 3 的条带（`n × 3`）都还没有定论（宽度 1 由 octal 理论解决；
宽度 2 有周期 2 定理；更宽的条带连"终期周期"这一命题本身都未知——见 O3）。

**O3. 条带的终期周期性。** `m = 2` 时序列周期为 2；`m = 4` 恒为 0。
固定 `m ≥ 3` 时 `G(m × n)`（关于 `n`）是否终期周期？对一维 octal 游戏，
"终期周期"是著名的未决问题；三行条带当前没有通用周期证明。
我们 `m = 3` 的数据推进到 `n = 28`，前缀不足以判断终期周期。notes/08 的
零尾巴定理已排除辅助序列 `a(n)` 的若干终期周期，但不直接约束整盘序列。

## 来自我们计算的开放问题

**O4. 3 × n 家族的长期行为。** 我们把 A316632 从 `n = 17` 推进到 `n = 32`（连续）：
`3×30` 由边行轨道证书确定为 P（notes/10 §11），`f(29)=1、f(31)=2、f(32)=6`
由"共享记忆全轨道扫描 + 中行分裂 + 反射 + mex"导出（RESULTS.md N20）。
新 P-位置仍只有 `3 × 22, 3 × 26, 3 × 30`。`n = 32` 之后下一个零点在哪？
（求解器已优化约 10×，但 `n ≥ 33` 受本机内存上限阻断——`A(32)` 的 union
≈1.4×10⁹ 状态超出单表 1.07×10⁹ 槽位。）

**O5. 4、8 列因子的作用。** `4 × n` 恒为 P（定理）。`8 × n` 呢？数据：
`8×1 = 8×2 = 8×4 = 8×5 = 8×6 = 8×7 = 8×8 = 0`，但 `8×3 = 2`（N）。
`8` 为偶数，偶×偶平凡为 0，所以问题只在奇数 `n`：`n = 1, 5, 7`（以及 3 之外的
已算值）都是 0。是否 `8 × n = 0` 对一切 `n ≠ 3` 成立？（需要更多数据。）

**O6. 3 × 4 为什么特殊？** `G(3×4) = 0` 是已发表 `3 × n` 范围内的唯一零点；
再加上 `3 × 22, 3 × 26` 也是零点——`G(3 × n) = 0` 的解集是无限的吗？稀疏吗？
（对比 `1 × n`：其 P-位置渐近密度为 11/34，见 T6。）

**O7. 奇×奇的天元只是故事的一半。** 3×3 与 5×5 的制胜首着**恰好**是四角 +
天元；但 7×7 有 21 个制胜首着（见 RESULTS.md §2.3）。刻画奇方盘的制胜首着集
合。（数据：`data/wmoves/`、`data/winning_moves.csv`。）

**O8. 超出乘积型配对的孤立零点证明。** `5×8`、`5×12`、`7×8` 在我们的数据里是
P-位置，但证书搜索（RESULTS.md N8）证明：**任何乘积型镜像策略都不可能**证明
它们。这个排除结论现已由 [notes/06](06_structural_pairing.md) 的分类定理
覆盖任意尺寸。接下来可研究任意固定配对或动态应答不变量。Brown 等人的
四列不变量本身就是乘积型固定配对，但不属于图自同构；不应称为“非乘积型”。
后续 notes/07 的完整分支反证进一步排除了这三个棋盘的任意固定配对。

## 猜想（仅数据支持，无证明）

**K1.** `G(6 × n) = 0` 对一切偶数 `n`（偶×偶，平凡）；而已算的奇数
`n = 1, 3, 5, 7, 9` 给出 `1, 3, 3, 3, 5`，全非 0。猜想：`6 × 奇数` 恒为
N-位置（与 `4 × n` 恒为 0 形成对比）。

**K2.** 已算范围（`n ≤ 28`）内 `G(3 × n) = 0` 只在 `n = 4, 22, 26`；
长期行为不猜（数据太少）。

**K3（撤回原表述）.** 全部矩形中 P-位置的渐近密度不可能为零：在
`1 ≤ m,n ≤ N` 中，仅偶×偶就贡献 `⌊N/2⌋²` 块，密度下界趋于 1/4。
若想研究“孤立零点”的稀疏性，须先定义排除哪些定理族以及如何取样；当前
数据是偏向路径和窄条带的非均匀样本，不能直接推出这样的密度猜想。

**K4（猜想 C，见 RESULTS.md N6）.** 若 `min(m,n) ≥ 4` 且 `4 | m` 或 `4 | n`，
则 `G(m × n) = 0`。已确认实例：`5×8 = 5×12 = 7×8 = 0`（非平凡），加上所有
一边为 4 的情形；待检：`9×8`、`11×8`、`5×16`、`7×12`。

## 方法学方向

**两根核心的双长段与长度差（2026-10-14）：**
[notes/23](23_two_arm_semilinear_algebra.md) 给出有限分区表的全选项核验定理。
核心内的保连通手进入真实较小核心；两侧尾巴前缀不再被当作独立 SG，必须
保留另一个长度。短段、模 4 余数、对角窄带中的准确长度差共同定义候选；
有界选项集引理使一个明确有限矩形内的全部 mex 检查推出任意双长度公式。
已独立核验完整厚块宽度 2–5 的四族，给出不要求等长的真实三行 P 无限族。
尚未证明任意核心都存在这种分区表。下一步的难参数是完整厚块宽度 w，
必须研究 w 变化时整个保根后继闭包的关系，而非拟合四个初态余数矩阵。

**两个任意厚核心的双侧连接（2026-10-14）：**
[notes/22](22_two_sided_comb_bridge.md) 将单侧交错尾巴推广为连接两个任意
核心的桥。两侧全部动态一端接口分别从 B_A、B_B 起周期 4 时，双侧自动
从 B_A+B_B+6 起周期 4；起点有核心大小的无条件二次上界。它已直接给出
真实三行不对称连通 P 无限族及长桥的准确 SG、制胜手，核心无需对称或
删除中性。未处理完整厚块中的保连通手；下一步可尝试把周期卷积从完全
分割着法推广到保留一个共享割点的动态状态，不能直接 xor 两侧裸 SG。

**删除中性接口与局部改写（2026-10-14）：**
[notes/21](21_neutral_core_absorption.md)证明连接点在全部相关后继中保持删除
中性时，核心可以吸收任意兼容配对外围，保留任意 nimber；外围配对甚至
无需自同构。新增的受保护孪生规则要求一个奇数叶子集和一个复制其余邻接集的
不相邻顶点，直接给出 `g(H)=g(C) xor 1`，严格推广两点尾巴。它识别三行
`U4664` 的四环—奇叶局部，直接得到 `U4664 → U462 + *1`。
同一节的二分图颜色类历史证明完整 `3×n` 厚块的任何顶点都不可能是删除中性
端口。未知厚核心尚未被求出。核心有限证书可以验证动态接口，但核心增大仍
可能指数；一般图的任意 nimber 构造不能冒充三行可达无限族。下一步应寻找
直接作用于完整厚块的连接恒等式，或证明空盘某类后继能够强迫进入已解结构；
继续搜集孤立端口等值不构成空盘规律。

**对称外围的精确消去（2026-10-14）：** [notes/20](20_guarded_symmetry.md)
证明固定中心的奇数个真正叶子会补偿镜像应答删除中心的奇偶变化，给出
`SG=(中心数+固定孤立点数) mod2`，外围可含任意大三行厚块和环。奇数宽
空盘上两手后仅删 7 格的连通局面已经有统一精确值 1 和显式制胜着。
下一步的关键是把空盘的任意首着后继纳入可证明的应答不变量，或刻画哪些
后继能强迫转入这些结构；仅存在指定的两手/四手历史不能给出空盘胜负。
对没有固定叶子保护的对称中心，当前公式不适用；不能把对称本身当作 SG 公式。

**全可达结构（2026-10-14）：** [notes/17](17_connected_history_language.md)
已经精确分类空三行盘所有历史后的连通几何：正则外行词、有限端点状态、唯一
规范化及反向合法见证。几何数严格满足三阶递推，完美编号把 SG 表压成每形状
一字节，跨度至 33 的全表约 9.21 GB；f(33) 尚未求得。内部落子都造成割点，
所有环只能在未落子段。下一步应研究厚块共享割点的完整游戏接口或任意上下文
替换，而不是再添加特殊形状模板。有限几何自动机不意味着有限 SG 接口，
目前未得到空盘的周期/零点分类。

**正面进展（2026-10-13）：** [notes/14](14_outer_defect_algebra.md)建立了全部两行
诱导局面的闭合区间递推、交替缺口尾巴的周期 4 闭式，以及单边连接任意固定
核心的有限周期提升条件。6 个真实可达三行头部已经通过独立核验，给出无限
长度的精确值、P 族和有限代表制胜着。后续
[notes/15](15_comb_stabilization.md)进一步证明任意 `k` 顶点核心都必然最终
周期 4，并给出统一 SG 界 `4(k+2)` 和二次起点界；核验窗口的存在性已解决。
这些结果未给出空盘规律。新的目标是放宽“第三行已消失”的条件，使区间或接口表示
仍对全部合法着法闭合；空盘全部三行仍存活时的外行着法是未解障碍。

**研究优先级修订（2026-10-13）：** notes/12 的两着分割已经提供有限 P 证书，
但尚未给出空盘序列规律；继续增加证书和辅助值不作为新的理论突破。
[notes/13](13_interface_obstruction.md)给出真实可达的接口反例：末三列完整、
64 项边界删除/闭邻域删除联合 SG 表相同的两个 `3×9` P 局面，接上一列后
SG 分别为 0 和 4。下一阶段应检验能保留全部合法后继的接口等价或任意长度
替换，目标是无限胜负族或闭合递推。此反例只否定声明的摘要，不否定一切
有限接口系统。以下路线记录保留为各阶段背景；`3×30` 已解决，`3×36` 未解决。

当前优先路线见 [notes/08](08_strip3_reductions.md)：对 `3×n` 先用端口条带
`A,D` 的中行分裂、零尾巴排除和等值证书筛选，再研究边行缺口家族。已精确算到
`n=28`，并得到无需求整盘 SG 的更长尺寸制胜证书。`3×30,36` 已排除所有中行胜着，
是下一批边行研究目标；两者的胜负仍未确定。

边行首着之后的端口族 `B,E,H` 已有完整切割与延伸引理
（[notes/10](10_strip3_ports.md)）：六条中行后继公式、`b/h` 反射对称、
零尾巴延伸不等式，以及 `B(10,4)` 的全着法结构和 126 个显式零回应。
`3×30` 的 15 个边行轨道已全部精确求出且非零（1.3–3.1 千秒/列），与既有
中行排除合并得到 `G(3×30)=0`（notes/10 §11）；`3×36` 仍是下一目标，
其 18 个边行轨道预计单列 0.5–2 小时量级。闭合性审计给出最小模板反例
（4 格爪形 `T4`：`B(3,3)` 边行第二着），并表明有限小词汇表对全部合法着法
不闭合——边行第二着需要新的结构表示。定向搜索的运行与交叉验证记录在
`data/strip3_target_30.json`。

一般棋盘的保留路线见 [notes/06](06_structural_pairing.md)：先解释 `5×8`，再测试同一
应答不变量能否覆盖 `5×12`，最后尝试对 `5×4k` 归纳。乘积型证书已有完整
分类，无须继续扩大该类穷举的尺寸。

后续推进见 [notes/07](07_fixed_pairing_and_responses.md)：三个孤立零点的任意
固定配对已全部被排除，下一步集中研究首着 `(3,2)`、回应 `(3,6)` 后的两个
中央接口，尝试构造能根据缺口变化的应答不变量。两步坐标均从 1 开始。

1. **条带的边界/转移矩阵方法。** 固定宽度的列前沿几何构型有限，但棋盘在
   前沿处不是"和的分解"，所以必须保留比前缀 SG 值更丰富的"接口游戏"信息。
   是否存在足够且有限的接口描述、是否在拼接和落子下闭合，
   都需要证明；不能先假定它只是有限个边界构型到 nimber 的函数。
   普通逐列 DP 或有限状态数本身也不自动给出 `3 × n` 的终期周期性。
2. **更大棋盘的对称规范化。** 把分量的规范形式从"平移/反射"扩展到完整的图
   同构归约（如 canonical labelling），可以合并更多记忆项。
3. **给孤立零点找证明。** 尝试用 notes/02 风格的配对/策略证明 `3×4`、`3×22`、
   `5×8`、`5×12`、`7×8`，或证明它们必须用别的方法（N8 已经把"乘积型镜像"
   这条路封死）。
4. **Misère（反规则）变体。** 本工坊的全部结果都是正常规则；反规则版
   （无棋可走者**胜**）是另一个游戏（一般图上 PSPACE-完全，Chandran et al.
   2024），值得单独建一个目录。
