# 39 —— 用两手回应证明接口的语义等价，及其逐列压缩的规模筛选

日期：2026-10-16。状态：`[充分条件推导]`、`[独立证书核验]`、`[有界实验]`。
目标仍为精确求出完整3×n到100；本轮没有新空盘值，也未通过快速复现到34。
以下是标准SG与镜像回应原理的接口应用，不声称首创。候选未替换默认求解器。

## 1. 这次检验的假设

notes/18–19的接口保留直接删除δ、端口着法μ、内部着法(T,后继)。只有递归
对象完全相同的两块才合并。这个条件比“接任意环境都同值”更强：无端口时，
所有SG相同的普通游戏都应合并，即使其着法树不同。

本轮允许有限的两手回应证明，将A换成B并独立异或k。命题是

```
Q(A,B,k)：对任意同端口的外部图C，
         g(A∪_I C) xor g(B∪_I C) = k。
```

这是**连接环境中的**结论；不以裸SG或端口删除表相同冒充等价。
失败只表示当前充分证明规则未知，不是找到了区分环境。

## 2. 可检查的充分条件

接口形式仍是notes/18的完整形式；状态(A,x)中的x是已经脱离的普通nimber。
证明Q时，改看两个独立的连接游戏`(A∪C)+(B∪C)+*k`，要证明它为P。
两份C互不相交；每份内部与自己的接口共享相应端口。

除恒等叶子Q(A,A,0)外，每个事实检查：

1. A、B具有相同活端口。对每个端口i，证明Q(δ_i A,δ_i B,k)。这些事实
   递归包含其余删除，故也覆盖外部手可能直接删除的任意端口子集。
2. 在同一端口i落子后，两侧幸存端口必须相同，并证明相应μ后继的Q。
3. 对A、B的**每个内部手**：若删端口集T非空，必须在另一块找到同样
   删T的内部回应，回应后满足更小的Q。若T为空，还允许在同一块再走一手
   不碰端口的内部手，或走剩余的独立Nim堆，使回应后满足Q。
4. 对Nim堆的**每个**合法手`k→j, j<k`，必须在某块中找到不碰端口的
   内部回应，使后继满足Q。不能遗漏这一项而错误地证明非零异或偏移。

脱离nimber用异或累积进目标；所有实际接口手完整保留。把一个脱离游戏换成
同值Nim堆使用的是析取和定理，因此证书中的虚拟Nim回应不一定对应脱离图
中的同名顶点着法，但它足以严格证明该实际后继非零。

**充分性证明。** 对接口节点序号之和归纳，并在同一对接口内对C的顶点数
归纳。对外部C内部的首手，在另一份C镜像回应，双方核心被直接删去同一个
端口子集，第1项保证回应后为P；没有端口被删时，使用更小C的内层归纳。
对公共端口的首手，在另一侧同名端口回应，第2项和后继对额外端口删除的
闭合性保证为P。两类内部首手与Nim首手由第3、4项提供回应。它们的证明
依赖严格降低接口序号之和，故不能循环引用自身。所有首手后继都有P选项，
原析取和为P，由SG异或得到Q。∎

新规则允许后继先不同，再经一手回到已证关系；包含原来递归对象相同的
替换，但没有证明这套规则捕获全部连接语义等价。

## 3. 实现与独立出口

`scripts/kayles_response_equivalence.py`实现上述充分关系及原接口的逐列合成。
新节点先按δ、μ的已归约后继及裸值构造候选桶；这些观察只用于筛选，合并
必须通过完整回应检查。候选的偏移由裸SG之异或唯一确定，没有猜值。

每条合并会保留准确的独立nimber偏移。连接和忘记端口在产生新节点时尝试
这种归约；原`BoundaryTransfer`新增的hook默认仍返回原节点和零偏移。
所有节点、候选关系及关系缓存均计数；没有只报告少了多少接口节点。

保存的例子以三格完整末列为端口，列词为

```
A = 573137，B = 463137；对任意末列环境C，g(A∪C)=g(B∪C) xor 1。
```

两块都是可达三行分量。这个具体关系也可由notes/21的受保护孪生规则说明，
本节把它作为**恢复已知数学恒等式**的检查例子，不重新包装为厚块突破。
它们的原始完整接口不同，新证明有64个接口节点、32个关系事实。

独立检查器`tests/verify_kayles_response.py`不导入构造器：先由既有独立顶点
集合检查器重建两块的全部441个相关诱导状态，验证每条δ、μ及内部手；
然后检查关系事实的全部首手、真实回应、Nim范围、端口同步和严格下降依赖。
它不调用新关系搜索或相信其布尔返回值。

小图核验约0.31秒，受2秒硬限额、单核、512 MiB约束：

* 5,350次至多四点核心接实际小图环境，与不分组件的顶点集mex一致；
* 全部512个3×3诱导掩码经过连接、忘记、重命名后的准确SG一致；
* 162次较长随机列词接实际环境、64个真实环境下的上述异或恒等式一致；
* 50组部分重合端口的连接、忘记与重命名，与实际顶点图递推一致；
* 漏内部手、漏Nim首手、错偏移、非法Nim回应、缺关系事实、缺接口手等
  八种损坏证书拒绝；工作量限额不会产生假的等价证书。

## 4. 规模筛选：节点减少，但关系证明开销很快超过节省

正式批次`data/kayles_response_screen.json`先跑相同逐列框架的原语法接口到10，

10列新接口节点少49.6%，但另需165,930个关系查询缓存项、372,992次裸值
递推选项；只证明160次合并。原框架这时裸值求值只访问6,566个节点。
保留的接口节点、关系项和mex选项单价不同，不能相加冒充总CPU指令或内存。

11列触及预设200,000个关系缓存项，立即未完成退出；不输出该宽度的SG。
候选10列约1.22秒，连11列失败共1.69秒；参考10列约1.14秒。单次墙钟
只说明量级，不作稳定速度比。**正式批次共约2.85秒，未延期或扩容。**

这没有超过已有定向求值的26/27列能力。仅看8→9→10的节点倍率约1.86、
1.85也看不到压缩在加速收敛；有限样本不是指数下界，但足以筛除当前实现。
逐列算子的表示仍展开了大量整个接口的后继，而求根SG未必需要这些关系。
本轮停止这项实现的规模扩张，不把节点减半当作通向100的充分证据。

下一步需要直接处理**完整厚块长度增长**时的参数关系或根查询的策略共享，
而不是继续追逐少量小末端的语义合并。新的方法仍须通过同样的秒级规模门槛。
