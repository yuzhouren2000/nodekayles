# 40 —— 空盘选项谱的结构：中行可分离，边行不可分离

日期：2026-10-16。状态：`[引用 notes/08、10 的推导]`、`[独立核验]`、
`[有界反实验]`。目标仍为精确求出完整 `3×n` 到 100；本轮没有新空盘值，
没有越过 28，也不更换默认引擎。

## 1. 动机

[notes/29](29_target100.md) §6 与 [notes/30](30_search_obligations.md) 把瓶颈
定位在高 SG 目标的证明（`E(F_28,4)` 归约到 `E(A(24),5)`）。若仍要攻 100，
C 方向需要一个新的**结构猜想**作种子。本轮检验其中最自然的一个：空盘每个
首着后的后继 SG 集合（选项谱）

```
opt_F(n, c, r) = SG( F_n 删去格子 (r,c) 的闭邻域 )      r ∈ {上,中,下}
```

能否坍缩成少数与宽度无关的通用序列。若能，则 `G(F_n)=mex(少数卷积)`，
宽度只是一个卷积下标，厚块瓶颈就有救。

## 2. 一个与 C 求解器无关的独立出口

`scripts/strip3_option_analysis.py` 不依赖 `src/cfast` 任何代码：位掩码 +
连通分量分解 + memo 的普通 SG 递推，对全体诱导子图求值。n≤16 的 `G(F_n)`
与已发表值逐项一致，作为对照；每块盘另求单缺口 `A(n)=F_n 删 (2,n)` 的值
`a(n)`。单核 n≤16 约 30 秒。

## 3. 中行是可分离的（已知定理，此处独立复现）

在 `(2,c)` 落子把第 c 列整列清空，左右两块恰为 `A(c-1)` 与 `A(n-c)`，故

```
opt_F(n,c,中) = a(c-1) xor a(n-c)。
```

这是 [notes/08](08_strip3_reductions.md) 的 F/A/D 中行分裂定理、
[notes/10](10_strip3_ports.md) §2 L1（取 `j` 无关的端口情形）的特例，
**不是新结果**。n≤16 的 105 个内部项 **0 违规**。用该恒等式从 `F_33/F_34`
的选项谱反推 `a(0..33)`，与 `data/strip3_language_gaps_32.out` 第二列
（即 `a(1..32)`）**逐项一致**，并命中独立锚点 `a(24)=9`、`a(33)=1`。

## 4. 边行不可分离（本轮的反实验）

在 `(1,c)` 落子删去 `(1,c-1),(1,c),(1,c+1),(2,c)`；剩余盘仍连通，
`(3,c)` 是割点。检验是否存在通用序列 `p,q` 使

```
opt_F(n,c,上) = p(c-1) xor q(n-c)。
```

GF(2) 上此形式的充要条件是每个 2×2“矩形”四角和为偶数。脚本枚举全部允许
矩形（n≤16、105 个内部项）：

| 行 | 2×2 违规 | 内部项 |
|---|---:|---:|
| 中（对照，定理保证可分离） | **0** | 105 |
| 上/下（假设） | **4468** | 105 |

故不存在任何可分离形式——单序列、双序列、以及 `a⊕a⊕t⊕t` 这类“可分离修正”
全部被证伪；边行值不是左右两侧任何函数的异或。这是
[notes/13](13_interface_obstruction.md) 接口障碍的一个**定量版本**：接口不是
有限语义。方法上要注意：只做“能否给未知量赋值”的传播会得到空洞的 0 违规
（内部约束图在剔掉两端列后失去锚点），**必须用显式 2×2 小式检验**，上面的
对照正是为此。

## 5. 两个附带的反实验

- **中行集不足以定 `G(F_n)`**：`mex{a(c-1)⊕a(n-c)} ≠ G(F_n)` 出现在
  `n = 1, 6, 10, 11, 12`（16 个尺寸中 5 个）。边行必然补上缺失的小值，
  所以只靠 `a` 与中行不够。
- **`A(t)` 选项谱不随 t 稳定**：`A(29)/A(30)/A(33)` 的逐列选项值没有公共
  前缀，也没有公共尾部，故不存在朴素的“远端子盘局部化”。

## 6. 结论与下一步

选项谱思路**不产生** C 需要的结构猜想：中行是已知的乘法分解，边行是实质
耦合，没有坍缩。建议不再沿“通用选项序列 / 有限接口”方向加码；这与
notes/13 的接口障碍、notes/29 §6 的判断相互独立地一致。若仍要攻 100，
新猜想必须直接处理边行割点 `(3,c)` 两侧的连接（连通而非乘积），否则
应改验收目标，见 notes/29 的替代方案。

复现：

```
python3 scripts/strip3_option_analysis.py --sizes 16    # 单核约 30 秒
```

本轮数据均由该脚本在线重算，未新增持久化数据文件；`a(1..32)` 的对照来源
为既有 `data/strip3_language_gaps_32.out`。
