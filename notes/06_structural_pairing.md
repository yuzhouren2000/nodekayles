# 06 —— 用结构定理替代乘积配对穷举

本节针对固定配对策略；不依赖 Grundy 数值表，不假定任何周期性。
以下是本工坊给出的完整推导，未核查这些结论的首创性。

## 1. 先区分三类策略

1. **对合自同构**：保持图的每条边，且配对点不同、不相邻。
   这是 notes/02 开头引理的条件。
2. **固定配对证书**：不要求保持每条边，只要求每次两手之后恢复配对不变量。
   这是 `scripts/pairing_certificates.py` 实际验证的条件。
3. **随局面改变的应答策略**：允许根据对手落子或当前缺口重新选择配对；
   不在上述证书类中。

第 2 类包含第 1 类。比如四行置换 `(1 3)(2 4)` 把行边 `2—3` 映到 `4—1`，
所以不是图自同构，但它是有效的固定配对证书。进一步要求
`φ(i,j) = (τ(i), σ(j))` 才是**乘积型**证书；任意格子配对未必能分离成行列置换。

## 2. 固定配对引理

设有限图的顶点集为 V，N[v] 为闭邻域。若 φ 满足：

* φ 是无不动点对合；
* v 与 φ(v) 不相邻；
* 对每个 v，`U(v) = N[v] ∪ N[φ(v)]` 在 φ 下不变；

则图上的 Node Kayles 是 P-位置，故 SG 值为 0。

**证明。** 保持“当前可下点集 S 在 φ 下不变”。对手在 v 落子后，φ(v) 原来
可下，且不在 N[v] 中，所以可以回应。两手之后可下集是 `S \ U(v)`；两个
φ-不变集之差仍不变。因此每次对手能走时都能合法回应，后手获胜。证毕。

注意，这里检验的只是充分条件。找不到这种证书，不代表先手必胜。

## 3. 路径引理：只有 P₄ 存在固定配对证书

**命题。** 对非空路径 Pₙ，存在上述固定配对证书，当且仅当 n = 4。

**证明。** 路径顶点按 `1,2,…,n` 编号。无不动点对合首先要求 n 为偶数。
设端点 1 与 j 配对；不相邻要求 j ≥ 3。任何 φ-不变集都由完整二元配对组成，
因此大小必须为偶数。

* 若 `3 ≤ j < n`，则
  `U(1) = {1, 2, j−1, j, j+1}`。
  当 j ≥ 4 时这五个点互异，违反偶数性。因此 j = 3，此时
  `U(1) = {1,2,3,4}`，由 `1↔3` 及不变性强制 `2↔4`。
  若 n > 4，`U(2) = {1,2,3,4,5}` 又是奇数大小。因此只能 n = 4。
* 若 j = n，n ≥ 4 时 `U(1) = {1,2,n−1,n}` 强制 `2↔n−1`。
  对这一对再用 U 的不变性，已配好的外层顶点之外只剩 `3,n−2`，于是强制
  `3↔n−2`。如此向内推进，必然强制中间的 `n/2↔n/2+1`，两点相邻，矛盾。
  n = 2 时端点本来就相邻，同样不行。

反过来，n = 4 的配对 `(1 3)(2 4)` 不配相邻点，两对的 U 都是整条路径，
所以满足条件。证毕。

这也解释了一个易混淆的例子：`G(P₈) = 0`，但 P₈ 没有这种固定配对证书。
“存在必胜策略”与“存在固定配对证书”是不同命题。

## 4. 矩形的乘积型证书完全分类

**定理。** 对正整数 m,n，矩形 `P_m □ P_n` 存在乘积型固定配对证书
`φ(i,j) = (τ(i), σ(j))`，当且仅当：

> m,n 都是偶数，或 m = 4，或 n = 4。

**必要性。** 若 m 为奇数，行对合 τ 必有固定行 r。由于 φ 没有不动点，
列对合 σ 没有不动点；同一行上的配对点也必须不相邻。

固定行 `R = {(r,j): 1 ≤ j ≤ n}` 自身在 φ 下不变。对该行中的任意格子
`v = (r,j)`，有

`U(v) ∩ R = {(r,k): k ∈ N_{P_n}[j] ∪ N_{P_n}[σ(j)]}`。

两个不变集的交仍不变，所以 σ 在这一行上满足路径引理的全部条件。
由路径引理，n 必须等于 4。交换行列可知：若 n 为奇数，m 必须等于 4。
剩下的可能就是两边都为偶数。

**充分性。** 两边均偶数时，180° 旋转是无不动点的图自同构，配对距离
至少为 2，满足引理。m = 4 时取 `τ = (1 3)(2 4)`、σ 为恒等：每对两行的
水平闭邻域相互交换，另两行的竖直邻格也相互交换，所以 U 不变。
n = 4 同理。证毕。

**推论。** 以下无限族都不存在乘积型证书，无须再枚举对合：

* 奇数 m 与偶数 n，且 n ≠ 4；
* 偶数 m 与奇数 n，且 m ≠ 4；
* 两边都是奇数。

特别地，`5×8, 5×12, 7×8, 3×22, 3×26` 虽然已知是 P-位置，却全部没有
乘积型证书。“τ = id、适用于所有行数”的列配对也只可能发生在 n = 4。
这是覆盖任意尺寸的证明；此前 `n ≤ 14` 等穷举结果只是它的有限验证。

## 5. 对项目研究方向的影响

**先集中研究 5×8 的应答不变量。** 它是现有数据中最小的、两边均大于 4 的
混合奇偶 P-棋盘。先解释这一例，再尝试 5×12，最后考虑整个 `5×4k` 家族。
对 `5×4k` 的讨论限定 k ≥ 1；k = 1 已由四列定理覆盖。

乘积型固定配对已经完全分类，继续增加这一搜索的行列上限不会带来新证书。
但仍有两条具体路线：

1. **任意固定配对。** 为每个非相邻点对 `{u,v}` 设置布尔变量，要求每点恰好
   属于一个选中对。任意两对 A、B，要求 `B ⊆ N[A]` 或 `B ∩ N[A] = ∅`，
   以及交换 A、B 后的相同条件；其中 `N[A] = ⋃_{a∈A} N[a]`。
   不满足时禁止这两对同时选中。这准确编码了 U 不变性，可用 SAT/约束求解
   搜索与行列不可分离的配对。得到的配对可由上述引理独立验算；UNSAT 只排除
   这个固定证书类，若作为正式计算证明发布还需保存编码及可复核的反证。
2. **动态应答不变量。** 从对手首着的对称轨道出发，提取已有精确求解器给出的
   可行回应，再寻找“回应后属于同一族”的有限形状描述。允许边界缺口、不同
   配对相位、局部重新配对。证明必须同时覆盖：初局属于该族；每个合法攻击
   都有合法回应；两手之后仍在该族；所以永远由后手完成最后一手。

不能把 `5×8` 当作两个独立的 `5×4` 来异或：两块之间仍有边，跨边界落子会
影响另一块。只有证明这些边在有关局面中不起作用，或明确记录接口的全部
博弈行为，才能使用分解。相同原因，普通独立集计数的列前沿 DP 不能直接
替代双方可在任意列落子的博弈；有限接口游戏是否闭合，本身就是待证明的内容。

对周期的观察也应保持有限样本措辞：27 项数据无法检验长度 60 的周期，且
任意有限前缀都不能排除更晚开始的终期周期。不要把“未找到”写成“已否定”。

## 6. 实现与验证

`scripts/pairing_certificates.py` 提供
`construct_product_certificate(m,n)`：存在时 O(m+n) 构造一组行列置换，不存在
时直接返回 None。`search(..., limit=1)` 使用这个分类；
`search(..., exhaustive=True)` 保留原穷举，便于独立检查。
默认脚本输出中的否定结果依据本节定理，不再声称它们来自逐项穷举。

运行 `python3 tests/test_pairing_classification.py`：对 `1 ≤ m ≤ n ≤ 6`
的全部 21 块棋盘独立穷举并对照分类，对路径 n ≤ 10 独立穷举；再对构造出的
多种尺寸逐首着模拟检查。小规模测试用于发现实现错误，任意尺寸的结论来自
上面的证明。

## 7. 计算层面仍需修复的问题

此次重点是证书与证明；以下是阅读源码时确认的独立问题：

* C 求解器的 `ht_grow()` 达到上限后返回，但 `ht_get()`、`ht_insert_raw()`
  仍无界线性探测。表满时不存在空槽，缺失键查找/插入不能终止。需要明确
  内存预算、负载阈值与退出/替换策略；仅延长超时不能解决这个问题。
* `run_campaign.sh` 把超时退出码 124 也标为 `.done`；重启时又以 `>` 覆盖
  结果文件。已输出若干行与任务真正完成、保存了搜索检查点是不同状态。
* 多条作业重复求解已知定理覆盖的空棋盘，并且各自保存大哈希表。若目标是
  找证明，应优先保存小例的回应与结构，减少并发跑更大空盘的投入。

这些问题不影响本节证明，但会影响长时间数值作业是否有效推进。
