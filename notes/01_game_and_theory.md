# 01 —— 游戏、Sprague-Grundy 理论及其结构

## 1. 游戏

局面：`m × n` 的格子棋盘，部分格子已放棋子（双方棋子同色）。棋子只能放在
空格上，且该格的上、下、左、右四个相邻格中都没有棋子。正常规则：轮到的
玩家无合法着法即**输**。

等价说法（标准名称）：这是图 `P_m □ P_n`（两条路径的笛卡尔积）上的
**Node Kayles**——双方轮流选择一个不与任何已选格相邻的格子，下出最后一手者
获胜。终局时的棋子集合总是方格图的一个**极大独立集**，所以这个游戏就是
"谁完成（下成）极大独立集"。

规则备注：
* 游戏有限（步数至多不超过独立数相关上界），胜负由"谁先无子可下"决定；
  没有和棋、吃子或隐藏信息。
* 游戏是**无偏的**（双方着法相同），因此适用 Sprague-Grundy 理论。

## 2. Sprague-Grundy 一页速览

对无偏游戏 `X`（正常规则），其 **Grundy 值 / nimber** 定义为
`G(X) = mex { G(X') : X' 是 X 走一步可达的局面 }`，其中 `mex` 是最小
非负整数集中缺失的数。本工坊反复用到的事实：

1. `G(X) = 0` ⟺ 轮到的一方必败（**P-位置**）；`G(X) > 0` ⟺ 轮到的一方
   必胜，且走到任意一个值为 0 的局面即可获胜（**N-位置**）。
2. **析取和**：若所有合法着法可分成若干互不影响的子游戏 `X_1, …, X_k`
   （在 `X_i` 中走子不影响任何 `X_j`），则
   `G(X) = G(X_1) xor … xor G(X_k)`（按位异或）。

## 3. 方格棋盘为何分解

对局中，**可下格集合**为 `P = 全棋盘 减去（棋子及其四邻）`。在可下格 `v`
落子会把 `v` 及其四邻从 `P` 中删去；因此 `P` 永远是若干"闭邻域之并"的补集。
若 `P` 在其诱导子图下分解为连通分量 `C_1, …, C_k`，则在 `C_i` 内落子只影响
`C_i` 的格子，由事实 2：

```
G(P) = G(C_1) xor … xor G(C_k),
G(C) = mex_{v ∈ C}  G(C 去掉 N[v])。
```

这正是精确计算可行的原因：同一个小形状的分量（经平移/反射规范后）在不同
棋盘中只算一次。递推只依赖分量的**形状**，与它在棋盘中的位置无关。

## 4. 复杂度备注

* 一般图：胜负判定 **PSPACE-完全**（Schaefer 1978），因此不指望存在对任意
  棋盘的多项式算法。
* 方格图：复杂度开放；精确计算随棋盘增大指数增长。窄条带可以用本工坊的
  方法算到相当长的序列（见 `notes/04_computation_log.md`）。
* Node Kayles 在"有界星形数"（bounded asteroidal number）的图类上有多项式
  算法（Bodlaender & Kratsch 2002）——该图类包含路径但不包含一般方格图，
  对条带也没有给出实用算法。

## 5. 本工坊的记法

* `G(m × n)`：`m` 行 `n` 列空棋盘的 Grundy 值。由转置同构，
  `G(m × n) = G(n × m)`。
* 状态标签 `[定理] [验证] [计算] [观察] [猜想] [开放]`，含义同 `RESULTS.md`。
* "条带"指固定 `m`、`n = 1, 2, 3, …` 的家族。

## 6. 基本小事实

* `G(1×1) = 1`，`G(1×2) = 1`，`G(2×2) = 0`（随便下，局势都是定死的），
  `G(1×3) = 2`，`G(1×4) = 0`（最小的"先手必败"非平凡棋盘）。
* 具有 180° 对称且两边都是偶数的棋盘是 P-位置——见
  `notes/02_symmetry_strategies.md`。
