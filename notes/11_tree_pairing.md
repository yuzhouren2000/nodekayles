# 11 —— 树上固定配对的完整结构分类与非对称三臂零点

日期：2026-10-13。本节沿用 notes/06 的固定配对条件，但把路径分类推广到
**所有有限树**。全部任意尺寸结论来自以下证明；有限穷举只负责独立核验。
标签为 `[推导]`，未核查该分类的首创性。

## 1. 固定配对与定理陈述

对有限简单图 `G`，固定应答配对指无不动点对合 `φ`，要求

1. `v` 与 `φ(v)` 不相邻；
2. 对每个 `v`，`U(v)=N_G[v]∪N_G[φ(v)]` 在 `φ` 下不变。

后手始终回应 `φ(v)`。条件 1 保证回应合法；条件 2 保证两手之后可下点集
重新由完整的配对组成，因此后手必胜，`G(G)=0`。找不到这种配对不等于先手
必胜，路径 `P₈` 就是值为 0 而无固定配对的反例。

**树分类定理。** 对任意非空有限树 `T`，以下两项等价：

* `T` 存在固定应答配对；
* 存在至少含两个顶点的树 `H` 与一条边 `ab∈E(H)`，使 `T` 同构于下列构造：
  取两份互不相交的 `H`，用 `v₀,v₁` 表示顶点 `v` 的两个副本，保留两份
  原树的全部边，再只加一条连接边 `a₀b₁`。

构造的配对是 `v₀↔v₁`。注意连接的两个顶点对应的是原树的一条**边的两端**，
而不是原树的同一个顶点。构造后总顶点数为 `2|V(H)|`，总边数为
`2(|V(H)|−1)+1`，所以仍是一棵树。

## 2. 必要性：边数强制唯一的三边块

设 `T` 有 `2k` 个顶点，`φ` 是固定配对。把每对作为一个二点块，将块间有边
当作商图 `Q` 的一条边。`Q` 是简单图，并且由于 `T` 连通，`Q` 也连通。

对任意两个块 `A={u,φ(u)}` 和 `B={v,φ(v)}`，一旦两块之间有边，块 `B` 的
两个顶点都必须落在 `N[A]=N[u]∪N[φ(u)]` 中（由 `φ`-不变性）。交换 A、B
后同理。因此两块之间的二分图**不能有孤立顶点**。

每块内部没有边。两块之间只有以下三种可能：

* 2 条边：必须是覆盖四个顶点的匹配；
* 3 条边：必须是四顶点路径 `P₄`；
* 4 条边：构成四环，和 `T` 为树矛盾。

令 `q=|E(Q)|`，令 `s` 是三边块间连接的数量。原树边数为

```
2k−1 = 2q+s.
```

又因商图连通，`q≥k−1`，故 `0≤s≤1`；左边是奇数，所以 `s=1`，
`q=k−1`。因此 `Q` 本身是一棵树，**恰好一对相邻块由 P₄ 的三条边连接**，
所有其余相邻块都只由两条匹配边连接。`k=1` 时不可能有这样的一条商边，
所以有效配对要求 `k≥2`。

在每条商边上选择一个覆盖对应四个顶点的匹配：普通连接恰好就是其两条边，
特殊 P₄ 连接选择它的两条外侧边。因为 `Q` 无环，可以从一个块开始标记两
个副本为 0、1，再沿商树传播标记，使所选匹配都连接同标号副本。这样所选
匹配边恰好组成两份 `Q`。

特殊 P₄ 中未选的中间边连接不同标号副本，且它的两端属于商图中相邻的两个
顶点。除它以外原树已经没有任何剩余边。因此原树就是两份同构树 `H=Q`
加上 `a₀b₁`，其中 `ab` 是 `H` 的一条边。必要性证毕。

## 3. 充分性与一个更一般的安全拼接规则

取两份 `H` 并加桥 `a₀b₁`，其中 `ab∈E(H)`，配对 `v₀↔v₁`。
同一个顶点的副本不相邻，因为新增桥的两个原顶点不同。对任意 `v`：

```
N_T[v₀] ∪ N_T[v₁]
  = {u₀,u₁ : u∈N_H[v]}.
```

当 `v` 不是桥端点时等式直接成立。当 `v=a` 时，新增邻点 `b₁` 本就属于
`N_H[a]` 的副本集合；当 `v=b` 时新增邻点 `a₀` 同理。因此每个闭邻域并集
由完整配对构成。固定配对引理适用，后手必胜，充分性证毕。

同一证明还给出更一般的**安全拼接命题**：`H` 可以是任意有限简单图，并且
可以沿原图边增加任意数量的跨副本边——对每条 `uv∈E(H)`，独立地选择是否
增加 `u₀v₁`、`v₀u₁`。所有这样的图仍有 `v₀↔v₁` 固定配对，SG 值为 0。
没有要求新增跨边本身成镜像。这是有具体接口条件的连接定理，证明依靠闭邻域
配对不变量，不能由“两块的 SG 相等”推出。

树分类是该构造在无环情况下的完整逆命题。森林不能逐连通分量声称每片都有
配对，因为配对也可以交换不同分量；本节的分类对象限定为连通树。

## 4. 三臂树推论：臂长必须是 1、t、t+2

令 `S(ℓ₁,ℓ₂,ℓ₃)` 是仅有一个三度顶点的三臂树，臂长按边数计，均为正。

**推论。** 对臂长排序 `ℓ₁≤ℓ₂≤ℓ₃` 后，该树存在固定配对，当且仅当

```
(ℓ₁,ℓ₂,ℓ₃) = (1,t,t+2),   t≥1.
```

**必要性。** 由分类，三臂树来自两份 `H` 加一条桥。若 `H` 含度至少 3 的
顶点，其两个副本在最终树中都至少三度，与最终树只有一个三度顶点矛盾。
所以 `H` 必是路径。新增桥把两个端点的度各加 1；为了最终恰有一个三度
顶点，桥的原端点 `a,b` 中一个必须是原路径端点（度 1），另一个必须是
内点（度 2）。又因 `ab` 是原路径的一条边，它必须是端边。

设原路径有 `q≥3` 个顶点。构造后的三度点到三个叶子的距离分别为
`1,q−2,q`，令 `t=q−2` 即得必要形式。

**充分性。** 取 `H=P_{t+2}`，在端边的两个不同副本间加桥，即得
`S(1,t,t+2)`。也可以不用同构构造，直接给出显式回应：记中心为 `c`，
短臂顶点为 `x`，另外两臂从中心向外编号为 `y₁,…,y_t`、`z₁,…,z_{t+2}`，
配对为

```
c ↔ z₂,   x ↔ z₁,   yᵢ ↔ zᵢ₊₂ (1≤i≤t).
```

由分类的充分性，这个配对有效，每个这样的树 SG 值为 0。

当 `t≥2` 时三条臂长互异，唯一三度点必须被所有图自同构固定，各臂随后也
只能逐点固定，故图自同构群只有恒等。上面的配对却把三度中心送到二度点，
严格超出了图自同构镜像策略。最小的非对称实例是 `S(1,2,4)`（8 个顶点）。

这不是分类三臂树的全部 P-位置：不符合臂长条件只证明没有这种固定配对，
仍可能有动态制胜策略。

## 5. 与三行棋盘的联系

该无限族可以嵌入两行（因此也可嵌入三行）条带的诱导局面：

```
{(2,j): 1≤j≤2t+3} ∪ {(1,t+1)}.
```

中心为 `(2,t+1)`，三条臂分别长 `1,t,t+2`。上边行只有那一个格子可下。
这个表示对应诱导可下图，不宣称每一个这样的掩码都可由空盘的合法对局到达。

其显式格子配对可以直接写成

```
(1,t+1) ↔ (2,t+2),
(2,t+1) ↔ (2,t+3),
(2,t+1−i) ↔ (2,t+3+i)  (1≤i≤t).
```

因此边行后继产生树形分量时，可以用结构分类识别 SG=0 的一族新形状，而不
必求完整 SG。它是已知 path/cycle/旋转词汇之外的严格归约依据。现有测量中
树形分量占比很低，本节不声称能靠该归约解决整个 `3×n`。

## 6. 可执行判定与独立核验

**识别算法。** 若顶点数为奇数直接排除。否则先找删除后两侧等大的边。树中
这样的边至多一条：切掉一条均分边后，任何其他边都在某半侧内部，它所切下
远离原桥的分量是该半侧的真子集，不能再次均分。

设唯一均分边为 `ab`，两半为 `A,B`，`a∈A,b∈B`。逐个尝试 `b` 在 `B`
中的邻点 `w`，检查根树 `(A,a)` 与 `(B,w)` 是否同构。若同构 `f` 存在，
则 `f(a)=w` 与 `b` 相邻，对应于原树边，且 `f⁻¹(b)` 与 `a` 相邻。由主定理
得到配对。若所有候选都失败，不存在固定配对。代码以迭代 AHU 根树类型
判定同构，复杂度上界 `O(n·Δ·log n)`，空间 `O(n)`；不枚举配对，也不求 SG。

```bash
python3 scripts/tree_pairing.py --spider 1 3 5 \
  --output /tmp/tree_pairing.json
python3 tests/verify_tree_pairing.py /tmp/tree_pairing.json
make test-tree-pairing
```

构造器输出完整邻接边、配对和桥，或结构性 UNSAT 原因。独立验证器不导入
构造器、搜索器或 SG 求解器：SAT 逐手重做攻击/应答的集合删除，并检查两半
同构见证；UNSAT 重找所有均分边，再用括号字编码独立检查每个可能根。

回归测试由“任意小树添一片叶子”生成每种非同构树，对所有完美配对做原始
条件枚举，与结构分类逐项比较；把顶点随机重编号后再比较；正例用无剪枝
子集递推确认 SG=0。它还覆盖任意小基树的每条定向边构造、全部小三臂参数、
长臂 `t=1000`，并拒绝漏配、假 UNSAT、假桥和重复边。

验证汇总与可单独检查的正反例在 `data/proofs/tree_pairing_examples.json`。
其中路径 `P₈` 同时保存 SG=0 与固定配对 UNSAT，防止把结构排除误写成胜负
判定。有限验证范围与数量以该文件的审计字段为准。
