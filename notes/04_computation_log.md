# 04 —— 计算日志：求解器、数据与核验

## 1. 实现

| 文件 | 语言 | 作用 |
|---|---|---|
| `src/nodekayles/solver.py` | Python | 参考实现（可读性优先） |
| `src/cfast/kayles.c` | C | 快速实现（大棋盘/长条带） |
| `src/cfast/strip3.c` | C | 三行专用实现、端口族和全部首着调查 |
| `tests/dumb_solver.py` | Python | 朴素 minimax（不用任何记忆化技巧），第三方意见 |

三套实现都遵循同一规格（notes/01 §3）：
`G(连通分量) = mex over 着法 of 子分量 G 的异或`，并把规范化的连通分量做
记忆化。C 版额外做了着法轨道剪枝。三套实现不共享代码（朴素版甚至不共享算法
思想），因此它们在同一棋盘上的一致是强证据。

## 2. 记忆化的规范形式

一个连通分量（格子集合）的键按如下步骤得到：

1. 平移到其外接矩形的原点；
2. 若矩形高大于宽，转置；
3. 在矩形对称群上取最小像（矩形 4 种变换；正方形 8 种：翻转、180° 旋转、
   转置）。

规范形式相同的分量 Grundy 值相同，共用一个记忆槽。同一进程内记忆跨所有棋盘
共享（条带作业因此能继承此前所有 `n` 的记忆）。

## 3. 数据工程

`scripts/run_campaign.sh`——幂等、可续跑；每个作业输出一个 TSV
（`m n G`）到 `data/raw/`，日志在 `logs/`。求解器每算完一块棋盘就 flush，
所以中途被杀也保留部分结果。

* `s1_1xn`：1 × n，`n = 0..1001`（专门的 O(n²) 递推，不走通用求解器——
  一行路径是 1001 位的大整数）。
* `s2_2xn` … `s8_8xn`、`s5b/s6b/s7b/s8b`：各条带，`n` 推进到状态数成为瓶颈
  之处；各家族实际范围见 RESULTS.md §2.1。
* `b9_9xn` … `b12_12xn`：9×9 直到 12×12 的棋盘（每个 `strip` 调用包含所有
  更小的宽度）。
* `data/wmoves/` 与 `winning_moves.py`：首手制胜着分析。

资源备注：C 求解器每条约 64 字节记忆项；条带作业哈希上限 2^24（约 1 GiB），
棋盘作业 2^25（约 2 GiB）。条带每加一列，探索到的规范分量数约乘 1.8–2
（实测 m=3：`n=20` 时 38.6 万条，`n=24` 时 440 万条，`n=26` 时 1490 万条），
这是长条带的实际障碍。3×n 的作业在 `n=28` 处撞上 2^25 哈希上限后显著变慢
（线性探测退化），最终由 2 小时超时终止并保留 `n ≤ 27` 的完整结果。

## 4. 配对证书（机器可验证的证明）

早期版本的 `scripts/pairing_certificates.py` 穷举乘积型对合
`φ(i,j) = (τ(i), σ(j))`，逐格直接核验证书三条件（枚举双方全部对合；按轨道
代表格检查；在声明的范围内是完全穷举）。结果：

* `4 × n`（一切 `n`）：证书 `τ = (1 3)(2 4)`、`σ = id`——Theorem 6 的一行
  机器可验证证明（行配对表述）。
* `2 × n`：有证书当且仅当 `n` 偶（验证到 14）；`1×4`、`3×4`、偶数×偶数
  （旋转）都有证书。
* **负结论**：P-位置 `5×8`、`5×12`、`7×8`，以及棋盘 `5×10`、`6×7`、`7×10`、
  `8×9`、`9×8`、`9×10`，**都不存在乘积型证书**（对相应规模穷举）。
  因此**乘积型固定配对**无法证明这些孤立零点；"τ = id"族（可一次性
  证明 `G(m × n) = 0` 对所有 `m` 成立）在 `n ≤ 14` 内**只对 n = 4 存在**。
* `tests/verify_certificates.py` 用逐步模拟镜像策略的独立方式再验证证书。

后续推导见 [notes/06](06_structural_pairing.md)：乘积型证书存在当且仅当
两边均偶数或某边为 4。当前脚本直接按定理分类并构造，原穷举保留为
`search(..., exhaustive=True)`。`tests/test_pairing_classification.py` 将分类
与小棋盘穷举、逐首着模拟分别交叉验证。

## 7. 如何继续推进

* 更长的条带：加大哈希上限（`KAYLES_HT_MAXBITS`，默认 25）与超时；困难区间
  每加一列大约时间与内存翻倍。32 GiB 以上内存可为 `m = 3, 4` 再买几列。
* 更大的方盘（12×12 以上）：同一算法可行但状态数爆炸；质的飞跃需要转移矩阵/
  边界（frontier）方法（研究课题，见 notes/05）。
* 给观察到但未证明的数值找证明：配对引理覆盖偶×偶、奇×奇、2×奇数的胜负；
  混合奇偶性的其余部分（尤其 `5×8`、`5×12`、`7×8` 这些镜像法失效的零点）
  都是开放的。
