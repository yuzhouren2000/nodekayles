# 30 —— 目标查询的三个替代展开，以及厚盘辅助族的具体障碍

日期：2026-10-16。状态：`[有限实验]`、`[独立小图核验]`。
本轮没有新增完整空盘的 SG 值，也未达到快速复现 1–34 的门槛；主目标仍为 100。

## 1. 为什么换展开方式

notes/29 的定向查询不必求出每个后继的完整 SG，但有两个可疑的开销来源：
一是分组件时仍先精确求值较小分量，二是固定着法顺序可能长期陷在难分支。
本轮实现并在同一有界筛选器中检验三个不同的展开方式，避免为未经检验的
设想直接启动大盘计算。默认限制仍为2秒/进程、单核、512 MiB；没有启动
服务器计算，也没有增加小时级作业。

本轮继续检验上一轮定向查询的可扩展性；完成小原型不代表主目标完成。

## 2. 联合查询多个未求值分量

对 `C1+…+Ct+*k` 直接做 P/N 查询，小分量和路径等已知值先异或到 k；其他
分量保留，允许在任何分量或 Nim 堆中落子。相同规范分量先抵消。缓存键是
排序后的**完整分量元组与 k**，哈希碰撞后逐项比较，不凭指纹判等。

这是普通析取和上的完整游戏搜索，理论上能绕过“先精确求完小分量”的要求，
但也可能产生更多元组。实现 `src/cfast/strip3_coupled.c`。

实验中24使用8,663个单分量缓存状态，另有416个元组状态；原定向查询为
8,586个单分量状态。26使用15,176个单分量状态和49个元组状态，原为15,171。
28仍在2秒停止。因此**当前实现没有扩展收益**，不是“联合查询一般不可能”。

## 3. 证明数搜索

将查询图视为 AND/OR 证明：节点命题是“该析取和为 N”。对全部图着法和
Nim 着法的后继，证明数取后继反证数的最小值，反证数取后继证明数之和。
用 DFPN 动态选择较可能解决的分支。搜索同样保留完整分量元组，已证明
单分量为 P 时发布其精确 SG，已证明为 N 时发布目标排除信息。

实现 `src/cfast/strip3_dfpn.c`。当前版本在展开时生成全部候选，24产生
170,589个证明节点、657,073条候选图着法，另有单分量缓存和证明边。
26在183,500个证明节点处触及其默认表限额，提前以未完成退出。

与定向查询相比，候选生成开销过大；**当前 DFPN 实现被筛除**。
这些数字不能用单分量的 `memo` 字段替代，也没有证明任何证明数算法的下界。

## 4. 用符号集合批量求 SG

实现一个带补边的约化有序二叉决策图（ROBDD），表示全体三行诱导掩码的
集合。变量是格子是否可用，按列排序；闭邻域删除对应将相关变量限制为0。

对集合 F，`Pre(F)` 是一步可走进 F 的全部掩码。假设已经分类出所有 SG<k
的掩码，令它们的并为 Q。固定点迭代为

```
初始 W=Q；
P=(非 Q) 且 非 Pre(非 W)；
W=Q 或 Pre(P)。
```

P是已证SG=k的集合，W是已证SG≠k的集合。Q中的局面可以通过降低额外的
Nim堆走到P，其余局面的真实图着法由Pre保留。每手严格减少格子数，所以
有限次迭代分类完成。即使完整集合尚未收敛，已经进入P的空盘也可安全输出。
唯一表比较完整节点键，节点上限失败不产生结果。

实现 `src/cfast/strip3_symbolic.c`。6已产生312,190个BDD节点，8在1,048,576
节点处触及上限。这个表示对全体诱导图做的工作太多，**当前表示被筛除**；
不能据此排除只表示可达语言或使用不同变量顺序的符号方法。

## 5. 保留的局部改进：共享已发现的选项值

一次查询虽只问“后继是否等于 k”，却可能顺带求出后继的准确 SG。旧原型
没有把这个值作为其他目标的排除见证传播回父节点。新增三个独立实验开关：

- `STRIP3_TARGET_SHARE_OPTIONS=1`：复用已发现的实际选项值；
- `STRIP3_TARGET_CACHE_FIRST=1`：递归前先找已经缓存的选项见证；
- `STRIP3_TARGET_FRONTIER=4`：面对≥4的目标，先试较小目标，寻找一个更小mex。

没有成本；总数仅是两类操作相加，也不是所有CPU指令数。

## 6. 按工作量停止，保存实际未完成的查询

增加 `STRIP3_TARGET_MOVE_LIMIT`，达到指定的递归着法数就以未完成退出，
记录当时最靠近根的12层查询。探查次数另计；这不是总指令预算，墙钟、内存
限制仍由筛选器独立执行。它使失败实验可复现，不必靠延长超时猜瓶颈。

在上面三开关配置下，750,000次递归着法的诊断得到：

```
E(完整3×28, 4)
  └─ 中行第4列：E(A(24), 5)
       └─ 外行后继与较小目标查询
            └─ 多处尚未分割的完整厚块……
```

`A(t)` 只删除末列中格。首步剩下A(3)+A(24)，已有数据A(3)=1，故查询目标
由4异或成5。已有完整survey另给出 **A(24)=9**：该查询答案是“否”，但定向
搜索仍要展开大量分支才能证明它。这里没有将9注入新求解器。

这只是一个确定工作量停止时的**实际未完成链**，不是证明它是所有运行中唯一
或最大的瓶颈。独立验证器以坐标集合删除闭邻域、分连通块、重新求矩形规范，
重放11步依赖；3个脱离小分量由独立子集mex求值。相同图下降目标的步骤也
单独检查。它验证诊断链的真实性，不冒充根查询的完成证书。

下一步比“继续优化28”更具体：研究A(t)及其厚块后继如何同时排除多个目标，
特别是值为9、11等较高SG时能否有可共享的证明。仅快速判断空盘P/N不足以
求出精确SG；只围绕最终目标0做策略优化会再次遗漏这层开销。
