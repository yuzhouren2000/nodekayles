# 37 —— 精确 SG 的历史条件组必为单点，去掉 BDD 不能靠 DNF 续命

日期：2026-10-16。状态：`[任意有限图的推导]`、`[独立核验]`、`[有界反实验]`。
目标仍是连续精确求出完整 `3×n, 1≤n≤100`。本轮没有新空盘值，没有越过28，
不更换默认引擎。未核查下述一般性质的首创性。

## 1. 为什么尝试条件组，以及实际发现的障碍

notes/36 的历史 BDD 版在10列只做5,354次查询，却新建5,330,298个BDD节点。
一个自然假设是：保存证明实际用到的正、负条件，避免建立完整布尔函数。
本轮实现了无BDD的条件组、精确查询缓存、三叉索引和局部推导证书。
小图验证后发现，索引在新历史上的泛化命中始终为0。这不是索引尚未调好，
而是这个表示和推导规则有一个严格障碍。

## 2. 条件组刚性定理：一组精确条件只能确定一个历史

令 G 是任意有限简单图，D 是它的全部独立顶点集。用独立集 S 表示已下历史，
令

```
f(S) = g(G − N[S])。
```

条件组（cube）由两个不交集合 Y、Z 给出，表示

```
B(Y,Z) = {S∈D : Y⊆S 且 S∩Z=空}。
```

Y是必须已下的点，Z是必须未下的点，其余不作要求。域外赋值怎样解释无关。

**定理。** 若 B 非空且 f 在 B 上等于同一个准确SG值，则 B 恰有一个成员。
更具体地，若 B 不止一个成员，可在线性图扫描内构造 B 中一步可达的两个历史，
它们的SG必不同。

**证明。** B 非空意味着 Y 独立，所以 Y 本身在 B 中。若还有 S≠Y，取
`v∈S−Y`。由于 S 独立且避开Z，v不邻接Y且不在Z中；于是 Y和Y∪{v}都在B中。
v在历史Y后是合法手，它的真实后继正是历史Y∪{v}，而一个局面的mex不等于
任何选项的SG。因此 `f(Y)≠f(Y∪{v})`，矛盾。∎

等价的直接检查：令

```
U = V(G) − (N[Y] ∪ Z)。
```

U非空时，任取v∈U即得到上述反例对；U空时B只含Y。
`scripts/history_cube_geometry.py::cube_witness`实现这个构造，不求SG。

**DNF推论。** 在独立历史域内，一个精确SG核若覆盖M个历史，用条件组的并
准确表示它至少需要M项；完整分类全部SG至少需要|D|项。即使核不完整，
对它实际覆盖的那M个历史，这个下界仍成立。

三行独立历史由列字母`0,1,2,4,5`和相邻字母按位不交计数，100列恰有

```
133018152636190047820581261240278825355410044173808533379
```

个独立历史，约`1.33×10^56`。这与notes/17的**不同连通几何**数量不同。
这个数字排除的是用DNF完整分类历史域，不是100列根查询的证书下界：根可能
只需要很小的部分核。定理也不排除BDD、仿射关系、策略关系或其他非凸表示，
更不是Node Kayles所有算法的复杂度下界。它不直接适用于可下格变量表示。

## 3. 本轮局部推导为何连否定条件组也不能泛化

P_k表示准确等于k，N_k表示不等于k。所有条件组都只使用先前已证事实：

- **否定的着法规则**：强制v合法；下v后进入一个P_k条件组，所以原组为N_k。
- **否定的较小值规则**：原组进入一个P_j条件组，j<k，所以为N_k。
- **肯定规则**：对每个顶点v，原组强制其不合法，或在v合法时后继进入N_k；
  原组还须包含于每个j<k的N_j。于是全部选项避开k，本身又不等于较小值，
  mex恰为k。

在合法v手的条件下，将后继条件拉回只需：去掉已下v的正条件；v的邻点必未下，
相应负条件可以去掉。已下点的邻点也由独立性自动为0，规范化时不重复存储。

肯定组由定理必为单点。合法映射`S↦S∪{v}`是单射，一个单点P组的合法逆像
仍至多是单点；较小值规则也只能继承一个单点。按推导顺序归纳，**这三个规则
产生的全部非空组，包括否定组，都只能覆盖一个历史**。因此在精确缓存未命中
的新历史上，索引也不可能命中。

这不是所有N_k条件组的下界：例如k大于顶点数时，全部历史都属于N_k。加入
其他广义否定规则可能产生更宽N组，但仍不能改变精确P组的刚性。本轮原型没有
注入这种界，也未加组件异或、图规范化或结构公式；它是表示反实验，不能拿它
的失败否定将其他机制结合起来的所有方法。

## 4. 不建立BDD的独立局部证书

`src/cfast/strip3_cube.c`保存上述推导。每条记录包含条件组、目标、真假、
规则，以及更早记录的引用。肯定规则逐个列出**全部顶点**的不合法阻挡点或
后继否定证明，并包含全部较小目标。否定规则列出真实着点或较小准确目标。

`tests/verify_strip3_cube_proof.py`不导入求解器或已有SG表。它从棋盘坐标重建
邻接和独立性，检查：条件可满足；字面条件蕴含；着法被强制合法；全部攻击
覆盖；目标与真假；引用严格指向先前记录；根包含空历史且证明准确值。
这是对推导记录的局部检查，无需对历史域分类或构造后继逆像BDD。
其成本由记录、引用、格数及位集操作决定，不需枚举`2^(3n)`个赋值。

保存的6列SG=3证明包含3,953条事实，其中1,106条肯定事实，7,591条真实证明
依赖，34,839个条件字面量。原文176,818字节，gzip后48,889字节。
全部事实的条件组另经刚性检查，确为单点。
C的`edges=20,771`统计的是存储槽，**包括不合法手的阻挡点**，不是7,591条
真实依赖。不能把两种计数混用。

此格式提供另一个独立核验出口，但当前构造器不扩展到大盘，不作为100目标
已获进展的证据。几何输入支持100列，测试仅使用39个接近终局的稀疏历史；
这些不是完整`3×100`的求解。

## 6. 非凸表示确实必要，但一个全局奇偶式仍不够

**正面的表示间隙。** 对m条互不相交边，独立历史有`3^m`种，而准确值只需
一个奇偶式：

```
f(S) = (m − |S|) mod 2。
```

因为每手恰删去一条尚未触及的边。SG=0的历史有`(3^m+1)/2`种，一个仿射
奇偶条件结合独立域即可表示；DNF却需要同样数量的单点组。这是精确的指数
表示间隙，不是完整三行盘的公式。

对一般图，若**全部极大独立集**大小同奇偶t，则所有终局的总手数同奇偶。
从任意合法历史S出发，终局剩余手数的奇偶为`t xor (|S| mod 2)`；每手翻转
这个量，按剩余点数归纳，全部后继均为相反的0/1值，mex给出

```
f(S) = t xor (|S| mod 2)。
```

这是一条直接准确求值的充分条件。三行图可以按相邻两列历史作独立支配集
转移，只需固定数量的状态；保存偶/奇两位支持信息，按列数线性时间判定。
不能用有正负抵消的计数值代替两种奇偶是否实际存在。

实际判定完整盘1..100全部同时有偶数、奇数的极大历史，故这个判据没有给出
其中任何一个准确值。对已保存的26列证书3,155种不同几何再检查，仅16种满足，
最大8个点；全部与原证书的真假相容。因此不将它加进热递归，也不继续调参。
混合奇偶只代表**判据未知**；例如完整`3×4`仍然SG=0。

而且一个仿射系统也不能覆盖整个`3×4`的零类。按列优先位编号：

```
历史             0        0xa       0x82       0x88
真实剩余图SG     0         0          0          2
```

后三个历史都是独立集，且`0xa xor 0x82 = 0x88`。包含0的仿射空间是线性子空间，
如果同时包含前两个非零零值历史，就必须包含它们的异或，矛盾。这个例子只
排除“一个仿射系统覆盖全部零类”，不排除多个仿射片段或较小的策略核。
表中的SG由不分组件的子集mex独立核验。
