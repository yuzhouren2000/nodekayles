# 21 —— 删除中性核心、外围吸收与任意前缀的两点尾巴恒等式

日期：2026-10-14。状态：`[推导]`、`[独立核验]`。未核查首创性。

本节将 notes/20 的叶子奇偶补偿推广成一个接口条件：核心的连接点在全部
相关后继中，直接删除都不改变 SG。满足这个条件的核心可以吸收任意大的
兼容配对外围，整图 SG 等于核心 SG；该值可以是任意非负整数。
配对甚至不必是图自同构。

另外证明两个不需要计算核心 SG 的局部规则：一个顶点若已有真正叶子，
再接一条两点尾巴，就使 SG 异或 1；更一般地，一个带奇数个叶子的顶点
若复制了某个不相邻顶点的其余邻接集，也使 SG 异或 1。它们给出任意三行
前缀的恒等式，也能作用在只删除常数个格子的真实三行后继上。这里没有
求出完整空盘的新值、周期或零点规律。

## 1. 删除中性必须对全部相关后继成立

设 K 是有限简单图，R 是指定连接点集合。连接点是普通可落子的顶点。
从 K 出发，允许两种操作来定义一个有限的查询闭包：

1. 真实着法：选择当前顶点 v，删除当前闭邻域 N[v]；
2. 接口查询：直接删除一个仍在图中的连接点 r。

第二项不是新的游戏着法，也不参与 mex；它描述外围着法可能对核心造成的
删除。记所有这样得到的诱导图为 X。如果每个 X 和每个幸存 `r∈R` 都满足

\[
g(X)=g(X-r),
\tag{1}
\]

就称 `(K,R)` 满足**遗传的删除中性**。连续删除几个连接点也保持 SG，因为
每一步仍在同一个查询闭包中。

只要求初态等值不够。按顶点 0,…,4 的邻接位掩码写，取

```
K = (6,1,9,20,8), R={0}.
```

K 是五点路径，0 是从一端数第二个顶点，`g(K)=g(K−0)=3`。在 0 上连接
两个相同的三点星的中心，扩图为

```
G = (102,1,9,20,8,641,1281,32,64,32,64).
```

交换两颗星是非相邻伙伴的对合自同构，却有 `g(G)=4`。K 的某个真实后继
破坏 (1)。这说明“当前 SG 相同”和“连接点在动态中可以被外围删除”不是
同一个条件。

## 2. 兼容配对外围吸收定理

将图 G 分成核心 K 与外围 E，核心连接点 R 恰为有外围邻点的核心顶点。
把 E 分成二点对，记伙伴映射为 σ。假设：

1. 每对 `{v,σ(v)}` 内部没有边；
2. 每个核心顶点对每对外围顶点都同时邻接二者，或者都不邻接；
3. 对每对 `{v,w}`，`(N_G[v]∪N_G[w])∩E` 是若干完整外围对的并；
4. `(K,R)` 满足第 1 节的遗传删除中性。

核心内部边任意，外围内部边任意，只须通过以上检查。条件 3 只限制两手
合起来删除的集合，不要求 σ 保持每一条边。

**定理。**

\[
\boxed{g(G)=g(K).}
\tag{2}
\]

**证明。** 按 G 的顶点总数强归纳，包含空核心、空外围。令 `t=g(K)`。

在核心 v 落子时，由条件 2，外围删除若干完整对。幸存外围仍满足条件 1–3；
核心成为真实后继 `K−N_K[v]`，其查询闭包包含在原闭包中。因此归纳给出
该手的整图后继值恰为 `g(K−N_K[v])`。核心选项都避开 t，并覆盖每个
`0,…,t−1`。

在外围 v 落子时，其伙伴 w 由条件 1 仍可下。再下 w 后，由条件 3，外围
仍由完整对组成。核心只被直接删除若干 R 中的顶点，故其 SG 仍是 t。
幸存图符合归纳前提，所以两手后整图 SG=t。于是 v 的一手后继有一个
SG=t 的真实选项，它自身的 SG 必不为 t。

这样，整图全部选项避开 t，且核心选项已覆盖所有较小值；mex 恰为 t。∎

**自同构不是必要条件。** 四点路径 `a-b-c-d`，配对 `{a,c},{b,d}`。两对
都是非相邻点，每对的闭邻域并都删掉全路径，但这个伙伴交换不保持边
`b-c`。它作为外围，仍可由 (2) 消去，只须核心对每对同时连接或不连接。

notes/20 是结构上容易识别的特例：每个中心带奇数个全图叶子，固定孤立点
独立。删除一个中心后，其奇数个叶子成为孤立点，补偿被删中心贡献的 1；
真实着法与多次直接删除也保持这一形式。本节允许其他核心和任意 nimber。

这条定理直接给出值，不计算外围 SG。对尚无解析结构判据的核心，验证条件
(1) 可能仍需指数多个核心状态，不能据此声称一般图或空盘已经多项式可解。

## 3. 两点尾巴的无条件局部恒等式

取任意图 C，其中 z 有一个真正叶子 t，即 t 在 C 中只邻接 z。添加新顶点 r，
使 r 只邻接 z 和新叶子集合 S；S 的大小为非空奇数，每个新叶子只邻接 r。
其余 C 顶点及边任意，记新图为 H。

单叶子时新增部分就是 `z-r-s`：

```
    t
    |
C — z — r — s
```

图示中的 C 可以通过 z 和其余原有顶点连接任意复杂的环境；t、r、s 的
接口条件须保留。

**定理。**

\[
\boxed{g(H)=1\oplus g(C),\qquad g(H-r)=g(H).}
\tag{3}
\]

而且 `(H,{r})` 满足遗传删除中性。

**精确 SG 证明。** 对 C 的顶点数归纳，允许 C 不连通。考察在 C 的顶点 x
落子，记原图后继 `C'=C−N_C[x]`。

- 若 x=z，r 被删，S 成为奇数个孤立点，后继值为 `1⊕g(C')`。
- 若 x≠z 且 z 被删，r 和 S 成为脱离的奇叶星，值为 1，后继值仍是
  `1⊕g(C')`。
- 若 z 幸存，它的原叶子 t 也幸存，后继具有同一构造；归纳仍给出
  `1⊕g(C')`。

奇叶星的所有着法都到 0，因此其 SG=1。在任一新叶子落子会删除 r，留下
偶数个新孤立点，后继值为 `g(C)`。到此为止，选项集合恰为游戏
`C ⊔ K₁` 的全部选项值，其 mex 为 `1⊕g(C)`。

还需处理额外的 r 手，它的后继为 `C−z`。在 C 的原叶子 t 落子，后继是
`C−{z,t}`；因为 t 在 `C−z` 中孤立，该手值为 `g(C−z)⊕1`。
由 mex，`g(C)≠g(C−z)⊕1`，也即 `g(C−z)≠g(C)⊕1`。所以 r 的额外选项
避开上述 mex，既不影响较小值的覆盖，也不改变 mex。得到第一式。

直接删 r 会留下 C 和奇数个新孤立点，证明第二式。

**遗传中性证明。** 任一真实着法后，若 r 幸存，则 S 全部幸存，且只有两种
情况：z 连同其原叶子 t 幸存，仍可用 (3)；或者 z 已被删，r 是脱离的
奇叶星，其值和删 r 后的奇数个孤立点同为 1。重复真实着法保持这两类形式。
直接删 r 后不再有活连接点。因此所有查询闭包状态都满足 (1)。∎

原叶子条件不能去掉：C 只有 z 一个孤立点时，接两点尾巴得到三点路径，
SG=2，而 `1⊕g(C)=0`。

这是一条可以直接识别并改写图的规则，识别条件不需要 SG 递推。
`leaf_support_reduction` 检查局部邻接后返回删去 r、S 的剩余图以及异或偏移 1。
多个满足条件的尾巴可以逐个消去，每次都重新检查条件；剩余图的 SG 仍可能未知。

## 3.1 受保护孪生的局部恒等式

两点尾巴只是一个更一般的“受保护孪生”构造的特例。设 C 是任意图，
选定顶点 t。向 C 添加新顶点 r 和非空奇数个新叶子 S，要求

1. 每个 `s∈S` 只邻接 r；
2. r 在 C 中的邻点集合恰为 `N_C(t)`；
3. r 与 t 不相邻（这也由第 2 条和简单图的对称性强制得到）。

令 H 为所得图。等价地，去掉 r 和 S 后，r 是 t 的一个假孪生点，并由
奇数叶子保护。则有可直接检查的恒等式

\[
\boxed{g(H)=g(C)\oplus1,\qquad g(H-r)=g(H).}
\tag{3.1}
\]

而且 r 是遗传删除中性端口：任何真实着法后的局面，只要 r 仍存在，
它仍是受保护孪生，或者已成为脱离的奇叶星；一旦某着法删去 r，端口
查询就不再有内容。

**证明。** 对 `|C|` 归纳。写 `Q=N_C(t)`，`B=C-N_C[t]`。在 H 中：

* 落在 C 中但不删去 r、t 的顶点，按归纳得到后继值
  `g(C')⊕1`；
* 落在 Q 的顶点会同时删去 r、t，S 则成为奇数个孤立点，后继仍是
  `g(C')⊕1`；
* 落在 t 或 r 后，剩余部分分别是 `B` 加一个奇叶星、或 `B` 加一个
  孤立 t，二者都为 `g(B)⊕1`；
* 落在 S 中任一叶子后，r 被删，其他叶子数为偶数，后继值为 `g(C)`。

因此除最后一类外，H 的选项值正好是 C 的全部选项值逐个异或 1（t 的
选项 `g(B)` 也包含在其中），另有一个值 `g(C)`。若 `n=g(C)`，C 的
选项集合含有所有小于 n 的整数且不含 n。异或 1 后的集合含有所有小于
`n⊕1` 的整数；当 n 为偶数时唯一缺口由叶子选项 n 补上，而 `n⊕1`
从未出现。故 mex 为 `n⊕1`。直接删 r 后留下 C 与奇数个孤立点，得到
第二式。上述两类残余构造对真实着法闭合，故同一论证也给出遗传删除中性。
∎

在三行图中，列词 `(...,4,6,6,4)` 的中间两个列块含一个四环。第一个
`6` 列的下格是 r，第二个 `6` 列的中格是 t；两者都邻接第一个 `6`
列的中格和第二个 `6` 列的下格。前一个 `4` 列的下格是 r 的唯一保护
叶，前方 `4` 列没有中格，保证 t 不与前缀相连。删除 r 及其保护叶后，
得到一个带单端口的四点路径。它与 `(...,4,6,2)` 的接口形状未必逐点同构，
需要再使用 notes/18 的边界替换递推（保留全部端口后继）才能识别其 SG。
该接口计算给出对任意前缀 U：

\[
\boxed{g(U,4,6,6,4)=g(U,4,6,2)\oplus1.}
\tag{3.2}
\]

式 (3.2) 与式 (5) 的 `U,4,6,4,4 → U,4,6` 规则不同：前者把一个真实
四环替换为树状末端，后者直接消去两点尾巴。两者都不要求 U 对称或已知
SG，因此可以作为局部归约反复应用；但归约后的厚核心仍可能有无界 SG，
它们没有给出完整空三行棋盘的周期或零点分类。

## 3.2 二分图中性端口的必要障碍

**定理。** 二分图中的遗传删除中性端口 r 必须带非空奇数个原始叶子。
“原始”指在查询闭包的初态中就只邻接 r。此条件必要，但并不充分。

**证明。** 设二分色类为 A、B，`r∈A`。依次在 `A−{r}` 的所有顶点落子。
它们彼此不相邻，因而全部合法，且不会删除 r。最终 A 中只余 r；B 中
幸存的非孤立点恰为 r 的原始叶子。其余幸存点均孤立。设原始叶子数为 k，
其余孤立点数的奇偶为 e。

当 `k=0` 时，保留与直接删除 r 的 SG 分别为 `1⊕e`、e。当 k 为正偶数
时，r 的分量是偶叶星，SG=2；直接删 r 则留下偶数个孤立点，SG=0。
两者总值分别为 `2⊕e`、e。都违反遗传删除中性。∎

五点路径的第二个顶点虽带一个原始叶子，却仍不满足遗传删除中性，说明
条件不充分。另一方面，完整 `3×N` 在 `N≥2` 时没有叶子；`N=1` 时的
中格有两个叶子、端格没有叶子。因此**完整空三行盘的每一个顶点都不是
遗传删除中性端口**。这对所有 N 成立，不是有限宽度实验的推测。

该障碍准确否定了把完整厚块直接当成删除中性核心的路线；它没有否定
带额外边界结构的接口等价，也没有否定 N29 的受保护对称后继。
`bipartite_port_obstruction` 输出一段合法历史；独立验证器只重放历史并
检查最终星和孤立点，无需 SG 搜索。

## 4. 连通的吸收核心可以取每一个 nimber

notes/16 §3 已证明：两行 n 列梯子删去左上角的图 `L_n` 有 `g(L_n)=n`。
`n≥2` 时，第二列下格 z 带第一列下格这个真正叶子。接 `z-r-s` 后：

\[
|H_n|=2n+1,\qquad g(H_n)=n\oplus1,
\qquad(H_n,\{r\})\text{ 遗传删除中性。}
\tag{4}
\]

给定目标值 `a≥2`，取 `n=a⊕1` 即可。值 0 用四点路径及其内点端口；
它也是 (3) 对 C=K₂ 的应用。值 1 用一条边及一个端口，直接检查即可。
这些都是连通核心，其外围可以任意增长而精确保持相应的 a。

这说明核心吸收现象不限于 P/N 的二分或奇偶值。不过 `L_n` 长族没有从
空三行盘产生的合法历史保证；(4) 及其配对扩图在这里是一般图结果。
度数和三行嵌入也须另行检查，不能称为三行空盘的任意 SG 无限族。

以下四个核心则有真正的空三行盘合法来源。位 1、2、4 表示上、中、下行；
端口都是第一列中格，即按列再按行编号的顶点 1（编号从 0 开始）。

| 核心列词 | SG | 查询闭包状态数 | 原空盘宽度 | 合法落子（行、列从 1 起） |
|---|---:|---:|---:|---|
| `73` | 3 | 11 | 4 | `(1,4),(3,3)` |
| `7646466` | 2 | 463 | 9 | `(1,3),(1,5),(1,8),(3,9)` |
| `76464677` | 5 | 2547 | 8 | `(1,3),(1,5)` |
| `764646776` | 4 | 5869 | 11 | `(1,3),(1,5),(1,10),(3,11)` |

这些值及端口的遗传中性由完整有限证书和独立原图递推核验。表中的对象是
历史后的连通分量，并非必然包括所有残余格。它们的端口度为 3；再接一对
邻点会超过方格度数 4。因此“这些核心真实可达”没有证明“任意配对扩图
仍是三行可达局面”。

## 5. 三行任意前缀恒等式及密集合法历史

令 U 是任意三行列词，允许全部字母 0,…,7，不要求对称、连通、周期，
也不限制完整三行厚块的长度。则

\[
\boxed{g(U,4,6,4,4)=g(U,4,6)\oplus1.}
\tag{5}
\]

最后两列下格是 r、s；它们的支撑点 z 是字母 6 的下格，它有同列中格
作为真正叶子。相邻列字母 4 都没有中格，所以这个叶子的唯一邻点确为 z。
U 与尾端的连接无法破坏这一性质，(3) 直接适用。上下反射也成立。

该恒等式有保留任意大厚块的真实来源。对每个空 `3×N`，`N≥7`，依次下

\[
(1,N-5),\quad(1,N-3),\quad(2,N-1).
\tag{6}
\]

三手都合法，留下列词

\[
7^{N-7},6,4,6,4,4,0,5.
\tag{7}
\]

其中 `7^k` 表示 k 个完整列，不是数值幂。恰保留 `3N−12` 格，密度趋于 1。
左区连通；最右 5 是被空列隔开的两个孤立点，其异或值为 0。因此

\[
\boxed{g(\text{(6) 后继})=1\oplus g(7^{N-7},6,4,6).}
\tag{8}
\]

这一式允许不对称、任意长的完整三行核心。它消去两个尾格且给出精确偏移，
但右侧厚核心的值仍未闭式求出，不能把 (8) 写成已解的 SG 无限族。
同样，存在三手历史不代表一方可以强迫对手采用该历史。

## 6. 可独立检查的实现与用途

`scripts/neutral_core.py` 只计算核心查询闭包，生成每个顶点子集及 SG 标签。
`tests/verify_neutral_core.py` 不导入生成器或 SG 求解器，逐条检查真实着法
的 mex、连接点删除等值、全部后继闭合、唯一根和状态完整性。配对证书还
保存原图、伙伴映射及抽出的核心，验证器独立检查第 2 节的全部外围条件。
外围无需求 SG。

```
make test-neutral-core
python3 scripts/neutral_core.py --core-word 76464677 --ports 1 \
    --output /tmp/neutral-core.json
python3 tests/verify_neutral_core.py /tmp/neutral-core.json
python3 scripts/neutral_core.py --paired-word 776464677 \
    --output /tmp/paired-core.json
python3 tests/verify_neutral_core.py /tmp/paired-core.json
```

独立原图核验包括：

- 不超过四点的所有简单图及全部端口集合，共 1,098 次查询；239 个获接受，
  其中包含空端口的平凡情形；
- 368 个穷尽的对称配对扩图、200 个随机扩图、92 个非自同构配对扩图；
- 150 个任意核心的奇叶星尾巴恒等式，梯子吸收核心宽度 2–9；
- 上表四个真实可达核心，585 个任意三行前缀尾巴恒等式；
- 宽度 7–17 的密集三手历史，独立坐标集合重放并核对全部残余格；
- 6 个完整空三行盘反射候选被拒绝（不含无外围的平凡情形），以及 5 个
  核心证书、5 个配对证书的篡改拒绝。

审计为 `data/proofs/neutral_core_audit.json`；SG=5 核心的完整 2,547 状态证书
为 `data/proofs/neutral_core_sg5.json`，真实三行列词 `776464677` 的外围消去
证书为 `data/proofs/paired_neutral_core_9.json`。有限实验是实现核验，无限结论
来自上述证明。
