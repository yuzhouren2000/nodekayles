# 08 —— 三行条带的结构化求解

本节把当前工作重点转到 `3×n`，并区分严格证明、机器核验和有限样本观察。

## 三个端口家族

记 `F_n` 为完整的 `3×n` 条带，`A_n` 为删去右端中间格的条带，`D_n`
为同时删去左右两端中间格的条带。用 `f(n),a(n),d(n)` 表示其 SG 值；三者在
`n=0` 均约定为空图，值为 0。`D_1` 只删除一次中间格。列从左到右编号。

**中行分裂定理 `[推导]`。** 中行第 `j` 列落子会删除整列及邻列的中格，
左右部分之间不再有边。根据各部分原有的端缺口，有精确恒等式：

| 原局面 | 中行着法的合法范围 | 着后 SG 值 |
|---|---|---|
| `F_n` | `1≤j≤n` | `a(j−1) xor a(n−j)` |
| `A_n` | `1≤j<n` | `a(j−1) xor d(n−j)` |
| `D_n` | `1<j<n` | `d(j−1) xor d(n−j)` |

证明只需检查缺口：完整条带切开后，两边各多一个端缺口；单端缺口条带切开
后，靠近原缺口的部分两端都缺中格；双端缺口条带切开后，两边均保留一个
旧缺口并获得一个新缺口。左缺口和右缺口条带由反射同构。

因此 `a(j−1)=a(n−j)` 当且仅当这一中行首着制胜。奇数 `n` 的中心列自动满足
等式；偶数 `n=2k` 的两个中心列制胜当且仅当 `a(k−1)=a(k)`。P-位置的必要条件是
所有 `j` 都不满足等值，特别是 `a(n−1)≠0`。这不是充分条件：`3×10` 没有中行
胜着，但边行第 4、7 列有胜着。同理，所有奇数 `n≥3` 的 `D_n` 都是 N-位置。

**零尾巴排除定理 `[推导]`。** 若某个 `t≥1` 满足 `d(t)=0`，则对所有 `k≥0`，

```
a(k+t+1) != a(k).
```

证明：在 `A_(k+t+1)` 的中行第 `k+1` 列落子合法，按分裂定理留下
`A_k + D_t`，值为 `a(k) xor 0`。SG 值是全部选项值的 mex，所以不等于该选项。

`D_1` 是两个孤立点，`D_2` 是两个不相邻的二点路径，因此它们都由两个同构
分量抵消而值为 0。这直接证明 `a(k)≠a(k+2)`、`a(k)≠a(k+3)`，无须任何大搜索。
调查还精确算得 `d(6)=d(10)=d(16)=d(24)=d(28)=0`，结合上面的普遍定理，将有限
尾巴计算提升为任意 `k` 的长度差 `7,11,17,25,29` 排除规则。这几个尾巴的零值
当前依赖计算，不能标成尺寸无关的结构证明。

完整棋盘的中行首着若两段长度差属于这些排除差，就不可能制胜。这个规则可用于
筛选胜着；精确计算整盘 nimber 时，非零选项仍可能影响 mex，不能据此全部跳过。

**辅助序列的周期障碍 `[推导]`。** 若 `a(n)` 最终具有周期 `p`，那么任何
`d(t)=0` 的 `t≥1` 都必须满足 `p` 不整除 `t+1`。否则，取足够大的 `k`，周期性
给出 `a(k+t+1)=a(k)`，与零尾巴定理矛盾。`D_1,D_2` 的直接证明已排除 `a(n)`
的终期周期 1、2、3；结合当前精确零尾巴，进一步排除 5、7、11、17、25、29。
这些是对所有起点成立的周期不可能性，强于有限前缀没有重复的观察；但它们不排除
其他周期，更不直接约束完整棋盘序列 `f(n)` 的终期周期。

## 从较短条带推出较长棋盘的制胜着

如果已算得 `a(p)=a(q)`，则在 `F_(p+q+1)` 的中行第 `p+1` 列落子后值为 0。
`scripts/analyze_strip3.py --json` 生成这种策略证书；它们不需要求出较长整盘的值。
例如 `a(9)=a(18)=2` 给出 `3×28` 的中行第 10 列胜着，`a(13)=a(18)=2` 给出
`3×32` 的中行第 14 列胜着。四个辅助值都已由原 C 求解器独立复核。

到 `a(28)` 的调查还给出以下未求整盘 SG 的偶数尺寸证书：

| 完整棋盘 | 中行制胜列（含反射） | 两段长度 | 相同 SG 值 |
|---|---|---|---|
| `3×32` | 14、19 | 13、18 | 2 |
| `3×34` | 13、22 | 12、21 | 3 |
| `3×38` | 19、20 | 18、19 | 2 |
| `3×40` | 16、25 | 15、24 | 9 |
| `3×42` | 21、22 | 20、21 | 3 |
| `3×48` | 22、27 | 21、26 | 3 |
| `3×52` | 24、29 | 23、28 | 2 |

这说明研究对象不应只有空盘序列：少量辅助条带值可以产生远超空盘搜索范围的
构造性胜着。但证书找到一手零值后继即可，不能由此得出整盘 nimber。

## 求解器中的严格归约

`src/cfast/strip3.c` 使用 126 位列主序掩码，连通分量分别记忆化。以下四项都
保持精确 SG 值：

1. 连通图若所有度数不超过 2，则它是路径或环。路径直接使用 Dawson 路径递推；
   环的每一手都留下同构的 `P_(k-3)`，故值为 `1` 当且仅当该路径值为 0。
2. 若局面在 180 度旋转下不变，且旋转不固定格子、也不把格子送到相邻格，
   镜像回应给出值 0。
3. 分解后的两个相同规范分量异或抵消。
4. 几何反射只用于把等价着法合并，不改变值。

这些归约的消融结果也很明确：到 `3×20`，主要加速来自紧凑位运算和三行专用
表示（这组样本相对原通用 C 求解器约 8 倍）；路径、旋转、分量抵消三项本身只略微改变
时间，分量抵消减少了递归调用，状态总数仍按列近似指数增长。归约结果也记忆化，
避免每次遇到同一个小分量都重做识别。不能把这三项宣传成主要性能来源。

所有程序用 `gcc -O3 -march=native` 编译、同一机器串行测速 `strip 20`：

| 模式 | 总时间（秒） | 记忆状态数 |
|---|---|---|
| 原通用 C | 10.842 | 385990 |
| 三行版，无定理归约 | 1.365 | 385997 |
| 仅路径/环 | 1.382 | 385997 |
| 仅安全旋转 | 1.388 | 385997 |
| 仅相同分量抵消 | 1.374 | 385997 |
| 三项同时启用 | 1.369 | 385997 |

这是一组运行样本，毫秒级差异不支持显著加速判断，机器同时有其他后台计算。
默认启用三项，允许 `STRIP3_REDUCTIONS=0..7` 做独立消融（路径=1、旋转=2、抵消=4）。
另试过树的完整图同构编码：相对原几何规范仅合并三个状态，耗时反而增加，已移出
正式实现。以图同构为更高层视角值得研究，但这一次实验没有提供有用收益。

哈希槽为 16 字节键加 1 字节值。默认最多 `2^26` 槽；达到 70% 负载就以退出码 3
报告预算耗尽，当前未完成的调查行不会输出。完整的 `survey 28` 需要 `2^27` 槽：
最终表约 2.125 GiB，扩容时新旧表共存约 3.188 GiB。总运行约 853 秒，`n=28`
这一行约 449 秒，累计 63184889 个记忆状态。

## 独立核验

`tests/test_strip3.py` 用完全不同的子集递推核验了 `3×5` 的全部 `32768` 个诱导
局面；八种归约开关的结果全部一致。另抽查了 327 个跨越第 64 和第 126 位的
稀疏局面，并把到 `n=20` 的 689 个完整、端口和首着局面送入原多字 C 求解器复核。

调查文件由 `scripts/analyze_strip3.py` 检查连续性、反射对称、每个首着的 mex、
已发表前缀和端口恒等式。有限样本只报告“observed”，周期搜索要求尾部至少四个
完整周期，不能据此宣称终期周期。

## 当前计算事实与下一步

精确空盘序列已推进到 `n=28`：

```
2 1 1 0 3 3 2 2 2 3 3 5 2 4 1 3 2 2 1 1 5 0 1 1 3 0 2 5
```

零点为 `4,22,26`。首着调查显示 `n=10` 是第一个“中行没有胜着、但边行有胜着”
的偶数尺寸。在 `n≤28` 的偶数尺寸中，中行没有胜着的恰为 `4,10,22,26`；边行
调查把其中的 `10` 排除，剩余三个就是当前零点。这个吻合来自完整选项调查，
不构成任意尺寸的充分条件。单端缺口的最大值已达 11，空盘首着后继最大值达
18，不能用空盘值至多 5 的有限观察给辅助局面强行截断 nimber。

定义 `B(n,j)` 为完整条带上边行第 `j` 列首着后的局面。它保留连续的下边行，
一般不能分裂成左右两个独立条带。由上下反射，只需研究一种边行；左右反射
又给出 `B(n,j)≅B(n,n+1−j)`。完整分类严格等价于检查中行的 `a xor a` 以及所有
`G(B(n,j))`，所以今后的新增工作应对准 `B`，而不是盲目扩大整盘搜索。

具体路线是：先以当前 `3×10` 的边行唯一类型胜着为小样本，研究 `B` 的中行切割
产生哪些带外行缺口的端口族；记录无法用现有 `A,D` 表示的第一类新几何形状。
找到闭合候选后，检验其落子与拼接是否都保留表示，并寻找可证明的等价关系。
三位列字母有限，不等于接口游戏的等价类有限；`F,A,D` 只在中行落子下部分闭合，
边行落子还未闭合。普通逐列独立集 DP 也不计算双方动态的最优胜负，不能直接套用。
周期证明只有在这些接口语义被控制之后才值得重新讨论。

进一步把“已知 `a(w)=a(p)`”与“零尾巴迫使 `a(q)≠a(w)`”串起来，可以排除一个
尚未求值的中行后继。逐着证据保存在 `data/strip3_analysis.json`：它排除了
`3×30` 和 `3×36` 的全部中行首着，未计算它们的整盘 SG 值。例如 `3×30` 的
端点首着比较 `a(0)` 与未知的 `a(29)`，两段差 29，由 `d(28)=0` 直接排除；
其余 14 类中行首着均比较已知且不相等的值。`3×36` 的未知长段也都能用零尾巴
和一个已知等值短段排除。这只排除了中行胜着，仍需调查边行，故适合作为下一批
结构研究目标。

复现入口：`make build-strip3`、`make analyze-strip3`、`make test-strip3`。
重新调查用 `STRIP3_HT_BITS=27 ./src/cfast/strip3 survey 28`；JSONL 原始值、
`data/strip3_analysis.json` 的证书与 `data/strip3_run.json` 的运行来源一起保存。
