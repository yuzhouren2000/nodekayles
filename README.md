# 方格棋盘上的 Node Kayles —— 研究工坊

本工坊研究的游戏（正常规则：无棋可走者负）：

> 在 `m × n` 的空棋盘上，双方轮流在空格放一枚棋子；放置时必须保证该格的
> 上、下、左、右四个相邻格中都没有棋子。轮到某人无格可放时，该玩家输。

这个游戏正是**方格图上的 Node Kayles**（也称"独立集游戏"）：棋盘对应图
`P_m □ P_n`（两条路径的笛卡尔积）；双方合力构造方格图的一个极大独立集，
下出最后一手（使独立集极大）的玩家获胜。

**结论总目录：[`RESULTS.md`](RESULTS.md)** —— 全部定理、精确值、猜想与开放
问题，都带有状态标签与证据出处。**从这里开始读。**

## 快速上手

```bash
make help            # 全部目标
make build           # 编译基础 C 求解器
make test            # 基础核验（对照文献，约 1 分钟）
make analyze         # 序列、周期、P-位置与全部校验
python3 scripts/play.py 5 5    # 与最优对手交互对弈
```

各专用求解器的用法、数据重算入口与逐条结论的复现方式，见 `make help`
以及 `RESULTS.md` 的相关条目。

## 研究现状

* **已解决的家族**：偶数×偶数（P）、奇数×奇数（N，天元制胜）、`2 × n`、
  `4 × n`（恒 P）、`1 × n`（即 Dawson's chess），以及一般配对引理。
* **主线 `3 × n`**：三行专用求解器把序列（OEIS A316632，原止于 17 项）连续
  推进到 `n = 32`；`G = 0` 恰在 `n = 4, 22, 26, 30`。`3×30` 已由边行轨道证书
  确定为 P，其余值由"共享记忆全轨道扫描 + 中行分裂 + mex"导出。
* **结构研究的边界**：notes 14–27 的成果集中在**有界厚块**周围的接口改写与
  局部闭式。最新结果（[notes/27](notes/27_bounded_thickness_search_lower_bound.md)）
  证明：即使免费求值全部有界厚块整组件，完整 SG 展开的状态指数率仍为
  Θ(ρ^N)，ρ = 1.839286…。因此局部公式不改变整盘搜索律。
  [notes/17](notes/17_connected_history_language.md) 给出全部可达几何的唯一
  正则语言与完美编号，是当前通向整盘规律的主要结构入口。
* **未决问题**：`G(3 × n)` 是否终期周期？方格盘全部 P-位置如何分类？格盘上
  胜负判定的复杂度？孤立零点 `5×8, 5×12, 7×8` 如何证明？
  详见 [`RESULTS.md`](RESULTS.md) 四、猜想与开放问题。

## 工坊惯例

* 基础求解器三套（Python 参考、C 快速、朴素独立实现）在所有抽查棋盘上交叉
  一致；另有三行专用与连通语言求解器。三行数据全部有独立进程复核。
* 可机器核验的内容全部核验：OEIS A002187 / A316632、Brown et al. 2020 表 1、
  以及每条结构性定理的证书与反例（证据文件见 `data/proofs/`）。
* 文档为中文，代码注释保留英文；每条结论在 `RESULTS.md` 中标注状态标签。
